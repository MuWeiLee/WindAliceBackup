| 项目 | 内容 |

## 需求背景与目标

机构管理人员需要在一个工作台维护成员、分配机构已采购的席位，并查询成员的对话、分享、下载和积分记录。原有方案以组织节点和节点权限为中心，无法直接作为这六项本期任务的交付范围。因此，本期以成员和逐个付费席位为管理对象，提供六个页面。上游企业管理系统负责企业创建、Owner 设置、采购席位总数和订单；工作台读取已购席位并管理其使用人。

本期原型使用浏览器本地数据，只用于评审页面与交互。真实账号、采购库存、内容记录、积分结算及权限控制尚待服务端接入。“本期目标”表示需要纳入需求讨论但尚未在原型实现；`[待确认]` 表示规则不能直接用于开发。

## 页面功能

### 公共框架与页面地图

左侧显示当前机构、功能菜单与用户入口；顶栏放当前路径和页面主操作。成员、席位页按概览、筛选、列表排列；记录页从查询条件和列表开始。分享链接与文件下载分设页面，不使用页内标签。

| 分组 | 页面 | 页面任务与主要区域 |
| --- | --- | --- |
| 成员与席位 | 成员管理 | 人数概览；搜索和状态筛选；成员列表；新增、编辑、启停、移除 |
| 成员与席位 | 席位管理 | 未分配付费席位的成员数与四类席位概览；席位筛选和逐席列表；分配、换人、释放 |
| 使用情况 | 对话内容 | 单个成员选择与时间筛选；对话列表；右侧问答详情 |
| 使用情况 | 分享链接 | 分享事件列表及分享类型、链接 |
| 使用情况 | 文件下载 | 下载事件列表及链接 |
| 积分 | 积分记录 | 积分事件列表及类型、描述、数量 |

### 成员管理

机构 Owner 打开成员页后，可看到当前未移除成员的总数、启用数和停用数；列表支持按人名、手机号、邮箱搜索，并按状态筛选。列表目标字段为成员 ID、人名、手机号、邮箱、加入时间、状态和操作。当前原型已有基础成员列表，但尚未显示成员 ID。

新增成员时录入人名、手机号、邮箱。当前机构存在相同手机号的未移除成员关系时，不允许再次加入；旧关系已移除时，允许建立新的成员关系，并产生新的成员 ID 与加入时间。新增成员默认启用、使用免费版。编辑成员仅可改机构内人名和邮箱，手机号只读。停用阻断机构访问但继续占席位；移除需二次确认，结束成员关系并释放其席位，历史使用记录仍归原成员 ID。当前原型已演示上述基本操作，跨机构查重与正式访问阻断仍需真实服务支持。

本期新增目标是在单个成员新增表单中选择已购且待分配的付费席位，并显示席位编号、余额与到期时间。若只选择席位类型而由系统挑选某一席，挑选规则 `[待确认]`。另一个新增目标是上传 Excel 批量添加成员：按表内成员顺序处理，拟录入人名、手机号、邮箱、期望席位类型；目标类型没有可用席位时按免费版加入。模板列、重复与无效行处理、同类型具体席位分配顺序和部分成功规则均 `[待确认]`。这两项当前原型均未实现。

### 席位管理

页面上部显示未绑定付费席位的成员数及其中可分配人数，并分别显示基础版、专业版、高级版、尊享版的已分配数、总数和待分配数。点击类型卡片查看该类全部席位，点击卡片中的“未分配席位”查看该类待分配席位；两种操作同步下方筛选并清空搜索词。列表还支持按席位编号、使用人或手机号搜索，按类型和分配状态筛选。

每个付费席位占一行，展示编号、类型、剩余积分、分配状态、当前使用人、到期时间与操作。待分配席位可分给当前机构内已启用且尚未持有付费席位的成员；已分配席位可更换使用人或二次确认后释放。分配与换人不改变席位编号或余额，释放后余额也留在席位上。候选人筛选之外，提交时仍须再次检查席位状态与成员是否已占席。若旧数据出现一人占多席，提示管理人员核对，不自动选择释放哪一席。

顶栏“发起席位调整”只告知机构需要发起席位调整工单或联系销售；本期工作台不提交工单，也不修改采购数量、席位类型或订单。免费版不形成逐席库存。当前原型已演示逐席管理和办理提示，展示的余额与到期时间是静态样例。

### 对话内容

查询区使用一个可搜索的成员单选框。输入人名、手机号或邮箱时只筛选候选成员；未选中成员时不展示对话。选中一人后，页面只查询该成员关系对应的记录，不能混入其他成员或同一账号再次加入后的旧关系。重新输入搜索词或切换成员时，立即清空上一人的结果。

时间选项为近 1 日、近 7 日、近 1 月和自定义，默认近 7 日。前三项按查询时刻向前滚动；自定义按起止自然日筛选并包含结束日，日期缺失或倒置时不展示结果。列表展示时间、成员 ID、人名、输入内容、输出内容、文件列表和操作。点击“查看详情”在右侧展开当前一条记录的完整问答与文件，可用关闭按钮、遮罩或 Esc 返回列表。当前原型已演示查询和详情，但列名仍使用“用户 ID”，须与成员 ID 口径统一。

### 分享链接、文件下载与积分记录

分享链接页展示时间、成员 ID、人名、分享类型和分享链接；分享类型包括 Link 看板、Chat 对话、单文件。文件下载页展示时间、成员 ID、人名和链接。积分记录页展示时间、成员 ID、类型、描述、数量。三类记录均应归属事件产生时的成员关系，同手机号重新加入时不得把新旧记录混合。当前原型分别展示三个页面，记录列名仍使用“用户 ID”；链接和积分均为演示数据，真实事件采集、链接访问及余额对账尚未接入。

## 数据字段

账号是登录身份，成员 ID 是一次加入某机构形成的成员关系标识，席位编号标识机构已购的单个付费席位。一个账号同时最多有一个有效的机构成员关系；一名有效成员同时最多持有一席付费席位。成员移除后再次加入可沿用账号 ID，但须产生新的成员 ID。使用记录保留产生时的成员 ID。

| 对象 | 本期字段 | 归属与约束 |
| --- | --- | --- |
| 账号 | 账号 ID、手机号 | 账号 ID 与成员 ID 分开；手机号是登录识别信息，机构内不可编辑 |
| 成员关系 | 成员 ID、机构 ID、账号 ID、人名、手机号、邮箱、加入时间、状态 | 每次加入生成新的成员 ID；状态为启用或停用，移除结束该关系 |
| 付费席位 | 席位编号、机构 ID、席位类型、剩余积分、分配状态、当前使用人成员 ID、到期时间 | 编号不随换人或释放变化；一席同时绑定零或一名成员 |
| 使用记录 | 记录 ID、机构 ID、产生时成员 ID、事件时间、记录内容 | 历史归属按成员 ID，不以手机号合并 |

各记录的页面字段如下。当前原型的“用户 ID”文案与最新字段规划存在差异；正式页面需明确展示的是成员 ID，账号 ID 保留为内部身份标识。

| 记录 | 页面字段 |
| --- | --- |
| 对话内容 | 时间、成员 ID、人名、输入内容、输出内容、文件列表、操作 |
| 分享链接 | 时间、成员 ID、人名、分享类型、分享链接 |
| 文件下载 | 时间、成员 ID、人名、链接 |
| 积分记录 | 时间、成员 ID、类型、描述、数量 |

席位需要能追溯其订阅订单，但订单到逐席编号的对应方式、续费是否沿用编号均 `[待确认]`。邮箱是否在新增时必填 `[待确认]`。席位余额、到期时间、事件记录的真实来源仍需上游系统或服务确认。

## 计算逻辑与交互方法

### 人数与席位统计

| 指标 | 计算规则 |
| --- | --- |
| 成员总数 | 当前机构未移除的成员关系数，包含启用与停用 |
| 启用数、停用数 | 分别统计未移除且处于该状态的成员 |
| 未分配席位成员 | 未移除且没有付费席位的成员，包含停用成员 |
| 其中可分配人数 | 未分配席位成员中状态为启用的人数 |
| 某类型总席位 | 该类型已购付费席位数，包含已分配与待分配 |
| 某类型已分配 | 该类型中已绑定成员的席位数；成员停用仍占用 |
| 某类型待分配 | 该类型总席位减已分配席位 |

免费版没有席位编号，不计入四类付费席位库存。席位余额绑定在席位上，释放或更换使用人时保留；旧使用人的对话、分享、下载及积分历史不会转给新使用人。真实积分扣减、每日上限、加油包到期和跨类型换档结算均 `[待确认]`，原型不据演示记录自动计算余额。

### 状态与操作约束

| 对象与动作 | 条件 | 结果 |
| --- | --- | --- |
| 成员停用 | 非 Owner 的未移除成员 | 状态改为停用；保留席位，阻断后续机构访问 |
| 成员启用 | 当前为停用 | 恢复机构访问资格；席位绑定不变 |
| 成员移除 | 非 Owner，完成二次确认 | 结束当前关系、释放席位；旧记录仍关联旧成员 ID |
| 席位分配 | 席位待分配，目标成员已启用且无付费席位 | 建立绑定，编号及余额不变 |
| 更换使用人 | 席位已分配，新使用人满足候选条件 | 席位改绑；旧用户的内容和历史不转移 |
| 席位释放 | 席位已分配，完成二次确认 | 解除绑定，改为待分配；编号及余额不变 |

如果分配或换人提交时，目标成员已被其他操作占席，页面应告知状态已变化并让管理人员重新选择。查询记录时，机构 ID 与成员 ID 均应限制结果归属；停用、移除之后对已打开会话和既有分享链接的具体失效时点 `[待确认]`。分享、下载、对话详情的可见范围、脱敏和保留期也 `[待确认]`。
