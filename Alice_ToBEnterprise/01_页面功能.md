# 机构工作台｜本期页面功能

> 基线：2026-10-14 本期范围，结合当日字段规划。页面面向单个机构，当前原型以 Owner 视角演示。文中“已演示”指本地单文件原型，“本期目标”指已提出但尚未在原型实现的功能；不代表真实服务已接入。

## 2. 成员管理

- 概览：成员总数、启用人数、停用人数。搜索支持人名、手机号、邮箱；可按状态筛选。
- 列表：成员 ID、人名、手机号、邮箱、加入时间、状态、操作。**成员 ID 是本期最新字段目标；当前原型尚未在成员列表展示。**
- 新增：录入人名、手机号、邮箱，新增成功产生新的机构成员关系和加入时间；默认免费版。**本期新增目标**是在表单内选择一席已购、待分配的付费席位，并看清席位编号、剩余积分和到期时间；当前原型只新增基础资料，席位需在席位页单独分配。
- 批量添加：**本期新增目标，原型未实现**。上传 Excel 后按文件中的成员顺序处理，拟包含人名、手机号、邮箱、期望席位类型；目标类型无可用席位时按免费版加入。文件格式、具体席位挑选顺序、异常行与部分成功规则待确认，不得直接按此段开发自动分配逻辑。
- 编辑：可改机构内人名、邮箱；手机号只读。非 Owner 成员可启用、停用或二次确认后移除。停用保留席位；移除释放席位，历史记录留在旧成员关系下。相同手机号再次加入生成新成员关系，不复用原加入时间。

## 3. 席位管理

- 顶栏“发起席位调整”只弹出办理指引：发起席位调整工单或联系销售。工作台内不提交工单、不修改订单或采购库存。
- 概览先展示未绑定付费席位的成员数及其中可分配人数，再展示基础版、专业版、高级版、尊享版各自的已分配数、总数和待分配数。免费版不生成逐席库存。
- 点击某类型卡片主体，筛选该类型全部席位；点击卡片的“未分配席位”，筛选该类型待分配席位。搜索支持席位编号、使用人、手机号，另有类型与分配状态筛选。
- 每个付费席位一行，显示席位编号、类型、剩余积分、分配状态、当前使用人、到期时间、操作。待分配席位可分配；已分配席位可更换使用人或释放。分配与更换只允许选择当前机构中已启用、未持付费席位的成员。释放需二次确认。

## 4. 使用情况与积分

- **对话内容：**一个可搜索的成员选择框，按人名、手机号或邮箱找候选人。必须选中一人才能查询，切换或重新搜索时清空上一人的结果。时间为近 1 日、近 7 日、近 1 月、自定义，默认近 7 日。列表展示时间、成员 ID、人名、输入内容、输出内容、文件列表、操作；“查看详情”在右侧展开完整问答及文件。当前原型列名仍写“用户 ID”，待与成员 ID 口径统一。
- **分享链接：**独立页面，展示时间、成员 ID、人名、分享类型、分享链接。分享类型包含 Link 看板、Chat 对话、单文件。当前原型列名仍写“用户 ID”。
- **文件下载：**独立页面，展示时间、成员 ID、人名、链接。当前原型列名仍写“用户 ID”。
- **积分记录：**展示时间、成员 ID、类型、描述、数量。当前原型列名仍写“用户 ID”；真实积分事件采集与结算未接入。

## 5. 本期边界

本期六页不包含组织架构、节点管理员、节点席位下拨、逐项功能开通、操作日志、企业订单或对话汇总。企业创建、设置 Owner、采购席位总数与订单属于上游企业管理系统。旧组织节点方案及其他后续方向见[未来计划](未来计划/README.md)；历史决策见[归档](归档/README.md)。
