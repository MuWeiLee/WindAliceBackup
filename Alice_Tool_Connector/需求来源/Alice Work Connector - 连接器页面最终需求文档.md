# Alice Work Connector - 连接器页面最终需求文档

版本：V1.0  
日期：2026-08-31  
范围：Alice Work 连接器市场、我的连接器、连接器详情、连接器配置、连接器接入流程、公众号连接器特殊能力

## 1. 背景

Alice Work 需要把外部工作系统、知识库、文档、邮箱、会议和内容源接入到 Alice 对话与任务流中。连接器页面承担三个职责：

1. 帮用户发现可用连接器和推荐组合。
2. 帮用户完成不同接入方式下的授权、凭证填写或接入申请。
3. 帮用户管理“已授权”和“是否开启调用”两个不同状态。

参考 WorkBuddy 的接入方式后，本页面沿用“连接器市场 + 接入方式分流 + 已连接管理”的框架，但在 Alice Work 中统一使用“连接器 / 连接器包 / 推荐组合”的产品语言。

## 2. 设计目标

1. 所有对外文案使用“连接器”，不再使用旧称。
2. “授权”和“启用”分离：用户完成授权后，也可以关闭连接器，使 Alice 暂停调用。
3. 危险操作收纳到“更多设置”，避免和常规信息区混在一起。
4. “我的连接器”使用卡片形态，和市场页视觉一致。
5. 新增“公众号”连接器，并在详情页支持搜索公众号、订阅公众号。
6. 推荐组合用于帮助用户理解一组连接器的协同能力，不产生独立授权状态。

## 3. 页面信息架构

### 3.1 顶部范围

页面顶部包含两个范围切换：

| 范围 | 说明 |
| --- | --- |
| 全部 | 展示推荐组合、分类筛选、全部的连接器卡片 |
| 我的 | 展示用户已授权的连接器卡片 |

搜索框文案：搜索连接器或推荐组合。

搜索规则：

1. 在“全部”范围内，搜索推荐组合名称、连接器名称、描述、样例用法。
2. 在“我的”范围内，只搜索已授权连接器。
3. 搜索为空时恢复当前范围默认列表。

### 3.2 分类筛选

分类位于“全部”范围内，仅作用于连接器卡片，不过滤推荐组合。

分类包括：

| 分类 | 包含连接器 |
| --- | --- |
| 知识库 | ima知识库、乐享知识库、Notion、知识星球 |
| 文档协作 | 飞书、腾讯文档、金山文档 |
| 沟通邮箱 | 钉钉、QQ邮箱、网易邮箱、企业微信、腾讯会议 |
| 文件资料 | 百度网盘、扫描全能王 |
| 内容资讯 | 公众号 |

## 4. 推荐组合

推荐组合展示为横向卡片，用于表达组合场景和关联连接器。

当前推荐组合：

| 推荐组合 | 包含连接器 | 定位 |
| --- | --- | --- |
| 微信生态 | 企业微信、腾讯会议、腾讯文档、QQ邮箱、ima知识库 | 覆盖客户沟通、会议纪要与团队资料 |
| 知识库 | ima知识库、乐享知识库、Notion、知识星球 | 聚合内部知识库、个人知识库和社群知识 |
| 邮箱 | QQ邮箱、网易邮箱 | 查询邮件、总结往来、起草回复和提取附件信息 |
| 文档协作 | 飞书、腾讯文档、金山文档 | 读取、创建、编辑和整理项目资料 |

交互规则：

1. 点击推荐组合卡片进入组合详情页。
2. 组合详情展示相关连接器列表、每个连接器的连接状态和单独连接入口。
3. 推荐组合本身不提供独立“一键授权”，因为不同连接器的授权主体、凭证类型和接入条件不同。
4. 组合内提示词只有在全部成员连接器均已授权且已开启时才可直接填入对话；否则引导用户连接缺失连接器。

## 5. 连接器市场卡片

连接器卡片字段：

| 字段 | 说明 |
| --- | --- |
| 图标 | 连接器识别标识 |
| 名称 | 连接器名称 |
| 描述 | 说明连接器可被 Alice 调用的能力 |
| 状态/操作 | 未连接时显示“+”；已授权时显示“已开启”或“已关闭” |

交互规则：

1. 点击“+”打开连接授权弹窗。
2. 点击卡片主体进入连接器详情页。
3. 已授权连接器卡片不再显示“+”，显示当前启用状态。
4. 搜索关键词命中卡片名称或描述时高亮展示。

## 6. 我的连接器

“我的”范围只展示用户已授权的连接器，使用卡片布局。

卡片字段：

| 字段 | 说明 |
| --- | --- |
| 图标、名称、描述 | 和市场卡片一致 |
| 分类 | 展示连接器所属分类 |
| 授权状态 | 固定为已授权 |
| 启用状态 | 已开启 / 已关闭 |
| 开关 | 控制 Alice 是否可以调用该连接器 |
| 设置 | 进入连接器详情或配置 |

状态规则：

1. 已授权且已开启：Alice 可调用该连接器。
2. 已授权但已关闭：Alice 不调用该连接器，授权关系仍保留。
3. 撤销授权后：连接器从“我的”范围移除。

## 7. 连接器详情页

详情页包含：

| 模块 | 说明 |
| --- | --- |
| 返回 | 返回连接器市场 |
| 连接器标识 | 图标、名称、分类、状态、开发者 |
| 启用开关 | 已授权连接器展示，用于开启或关闭调用 |
| 更多设置 | 包含配置连接器、撤销授权 |
| 立即体验/连接 | 已授权且开启时进入对话；未连接时打开授权弹窗；已关闭时不可用 |
| 能力样例 | 展示可点击的自然语言调用样例 |
| 信息 | 功能、开发者、类别、版本、启用状态、调用方式 |

详情页状态规则：

| 状态 | 主按钮 | 开关 | 更多设置 | 样例点击 |
| --- | --- | --- | --- | --- |
| 未连接 | 连接 | 不展示 | 不展示 | 打开连接弹窗 |
| 已授权 · 已开启 | 立即体验 | 开启 | 展示 | 填入对话输入框 |
| 已授权 · 已关闭 | 立即体验置灰 | 关闭 | 展示 | 打开连接/开启引导 |

危险操作规则：

1. 撤销授权只出现在“更多设置”菜单内。
2. 点击撤销授权后弹出确认弹窗。
3. 确认撤销后，清除授权状态和启用状态。
4. 撤销授权不删除历史对话中的引用内容。

## 8. 配置页

配置页由“更多设置 -> 配置连接器”进入。

配置页字段：

| 字段 | 说明 |
| --- | --- |
| 连接器状态 | 未连接、已开启、已关闭 |
| 允许 Wind Alice 调用 | 启用开关，仅已授权时可操作 |
| 授权方式/凭证字段 | 根据接入方式展示 OAuth、访问凭证、邮箱授权码、管理员安装或合作接入状态 |
| 保存配置 | 保存当前配置，返回详情 |
| 状态刷新 | 刷新连接状态 |
| 撤销授权 | 已授权连接器展示，触发二次确认 |

## 9. 公众号连接器特殊需求

公众号连接器属于“内容资讯”分类，不只是普通授权连接器。它的完整路径是：

1. 用户在市场页找到“公众号”连接器。
2. 用户点击连接，弹窗展示“内容源订阅”接入方式。
3. 用户点击“开启连接器”，连接器进入“已授权 · 已开启”状态。
4. 用户进入公众号详情页。
5. 页面展示“公众号订阅”模块。
6. 用户搜索公众号名称或微信号。
7. 用户点击“订阅”。
8. 已订阅公众号进入订阅清单。
9. Alice 后续只检索用户已订阅公众号的文章和更新。

公众号订阅模块字段：

| 字段 | 说明 |
| --- | --- |
| 搜索框 | 支持公众号名称、微信号、描述关键词 |
| 搜索结果 | 展示公众号头像、名称、微信号、描述 |
| 订阅按钮 | 未订阅时展示“订阅” |
| 已订阅状态 | 已订阅后展示“已订阅” |
| 已订阅汇总 | 展示已订阅公众号数量和名称 |

公众号状态规则：

1. 连接器未授权时，不展示订阅模块。
2. 连接器已授权且已开启时，可搜索、订阅并在对话中调用。
3. 连接器已授权但已关闭时，订阅关系保留，但 Alice 不调用公众号内容。
4. 撤销授权后，前端应清除或隐藏调用入口；订阅关系是否保留由后端策略决定，建议保留 30 天用于重新授权恢复。

## 10. 连接器接入方式

参考 WorkBuddy 的接入方式，Alice Work 连接器按接入类型分流：

| 接入方式 | 适用场景 | 页面表现 | 当前连接器 |
| --- | --- | --- | --- |
| OAuth 跳转授权 | 第三方平台提供用户授权页 | 展示“前往授权”，完成后返回 Alice | 腾讯文档、金山文档、百度网盘、Notion、钉钉、扫描全能王 |
| 访问凭证 | 用户需要在外部平台获取 key、token 或授权码 | 展示凭证输入表单，保存后连接 | ima知识库、飞书、乐享知识库、网易邮箱、腾讯会议 |
| 管理员安装 | 需要企业管理员安装应用或授权组织资源 | 展示管理员安装说明和模拟完成入口 | 企业微信 |
| 内容源订阅 | 授权后还需要选择内容源 | 先开启连接器，再在详情页搜索并订阅内容源 | 公众号 |
| 合作/暂不可自助接入 | 第三方暂无稳定开放能力或需要平台合作 | 展示不可自助接入说明，不允许直接连接 | 知识星球、QQ邮箱 |

接入安全要求：

1. 授权信息和访问凭证必须隔离保存到用户个人空间。
2. 前端只展示脱敏状态，不展示明文密钥。
3. 连接器必须支持重新授权、关闭调用、撤销授权。
4. 连接器调用前必须同时校验“已授权”和“已开启”。
5. 推荐组合调用前必须校验组合内每个连接器的状态。

## 11. 状态模型

连接器需要拆分为三个状态：

| 状态 | 含义 | 示例 |
| --- | --- | --- |
| 接入可用性 | 平台是否允许用户连接 | 可自助接入、需管理员、暂不可接入 |
| 授权状态 | 用户是否完成账号授权或凭证保存 | 未连接、已授权 |
| 启用状态 | Alice 是否允许调用该连接器 | 已开启、已关闭 |

最终可调用条件：

```
canUseConnector = accessAvailable && connected && enabled
```

展示文案：

| connected | enabled | 展示 |
| --- | --- | --- |
| false | false | 未连接 |
| true | true | 已授权 · 已开启 |
| true | false | 已授权 · 已关闭 |

## 13. 验收标准

1. 页面中不出现旧称，顶部范围展示“全部 / 我的”。
2. 全部页展示 15 个连接器和 4 个推荐组合。
3. “我的连接器”使用卡片样式，不使用列表行样式。
4. 普通连接器可打开授权弹窗，按不同接入方式展示不同说明。
5. 已授权连接器支持“已开启 / 已关闭”切换。
6. 已关闭连接器保留授权，但“立即体验”不可点击。
7. 危险操作“撤销授权”只在“更多设置”中出现。
8. 配置页支持查看状态、启用开关、保存配置、刷新状态和撤销授权。
9. 公众号连接器连接后，详情页展示公众号搜索和订阅能力。
10. 推荐组合详情展示相关连接器，并按单个连接器处理授权。
