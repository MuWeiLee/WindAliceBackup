# 连接器弹窗文案

本文档整理 Alice Work 连接器原型中“连接弹窗”的全部文案。当前版本已删除弹窗副标题，并尽量抽象可复用文案。

## 通用文案模板

### 标题

```text
连接 {连接器名称}
```

### 填写凭证类

接入方式标签：

```text
填写访问凭证
```

接入方式说明：

```text
请前往 {凭证获取地址名称} 获取相关的凭证信息。填写并保存连接后 Wind Alice 即可调用您的{连接器能力}。
```

其中 `{凭证获取地址名称}` 需要做成超链。

安全说明：

```text
相关凭证信息将会隔离保存到您个人的空间，后续可在设置中重新授权或撤销授权。
```

主按钮：

```text
保存并连接
```

### 跳转授权类

接入方式标签：

```text
跳转授权
```

接入方式说明：

```text
将跳转到{连接器名称}授权页。完成授权后 Wind Alice 即可调用您的{连接器能力}。
```

安全说明：

```text
授权完成后，相关授权信息将会隔离保存到您个人的空间，后续可在设置中重新授权或撤销授权。
```

主按钮：

```text
前往授权
```

### 合作接入类

接入方式标签：

```text
合作接入
```

接入方式说明：

```text
{连接器名称}当前需要平台合作接入，暂不支持用户自助连接。
```

安全说明：

```text
开放后将提供授权状态、重新授权和撤销授权能力。
```

主按钮：

```text
申请接入
```

点击后按钮文案：

```text
已提交申请
```

### 暂不可自助接入类

接入方式标签：

```text
暂不可自助接入
```

接入方式说明：

```text
{连接器名称}当前暂不支持自助连接。后续具备稳定开放方案后，可再开放连接入口。
```

主按钮：

```text
暂不可连接
```

### 连接器包

标题：

```text
连接 {连接器包名称}
```

接入方式标签：

```text
批量连接
```

接入方式说明：

```text
将按连接器包配置依次连接下方能力。Demo 中点击“一键连接”会模拟全部连接成功。
```

主按钮：

```text
一键连接
```

成员状态：

```text
已连接
待连接
```

### 示例区

示例区标题：

```text
可以这样用
```

说明：

```text
连接弹窗里的示例仅作为能力预览，未连接前不可直接使用。
```

## 单连接器文案

## ima知识库

接入方式类型：填写凭证类

标题：

```text
连接 ima知识库
```

凭证获取地址：

[IMA Agent Interface](https://ima.qq.com/agent-interface)

连接器能力：

```text
ima 知识库资料和文件能力
```

接入方式说明：

```text
请前往 [IMA Agent Interface](https://ima.qq.com/agent-interface) 获取相关的凭证信息。填写并保存连接后 Wind Alice 即可调用您的 ima 知识库资料和文件能力。
```

输入框：

```text
客户端 ID
请输入客户端 ID

访问密钥
请输入访问密钥
```

安全说明：

```text
相关凭证信息将会隔离保存到您个人的空间，后续可在设置中重新授权或撤销授权。
```

主按钮：

```text
保存并连接
```

可以这样用：

```text
在 ima 知识库中搜索「季度复盘」相关的资料
查看「产品手册」ima 知识库的详情和文件列表
引用 ima 知识库中关于 OpenAPI 的内容回答这个问题
```
