# 机构管理平台页面架构与交互说明 V1.0

> 与《01_机构管理平台_PRD_V1.0.md》配套。2026-10-13 已补充五级组织架构与组织管理员需求。原型为桌面 Web 管理控制台，Alice 用户端只以示意视图呈现。内容中标为「演示」的状态不会操作真实用户和机构。

## 1. 平台与页面地图

```text
入口
├─ Alice 当前机构上下文 →「机构管理」→ 独立控制台
└─ 管理平台地址 → 统一身份登录 →（管理多个机构时）选择机构

机构管理平台
├─ 机构概览
│  ├─ 机构服务状态 / 席位 / 积分 / 待办
│  └─ 最近管理行为
├─ 成员管理
│  ├─ 成员列表 → 一级至五级架构 / 成员详情 / 编辑 / 禁用 / 启用 / 移除
│  └─ 邀请记录 → 新建 / 取消 / 重发
├─ 组织架构
│  ├─ 最多五级节点画布 → 拖拽布局 / 新建 / 关联 / 解除 / 停用
│  ├─ 节点详情面板 → 名称 / 层级 / 上下级 / 人数
│  ├─ 节点管理员 → 从全机构成员添加 / 撤销
│  └─ 组织统计 → 直属与汇总用户 / 用量 / 使用情况
├─ 内容管理
│  ├─ 对话请求 → 只读详情
│  ├─ 生成素材 → 只读详情
│  └─ 分享链接 → 记录详情
├─ 权限设置
│  ├─ Admin 管理动作权限
│  └─ Member 功能权限
├─ 使用与额度
│  ├─ 席位台账
│  └─ 积分消耗
├─ 操作审计
└─ 机构信息（上游只读）
```

导航以机构为工作范围：左侧是一级模块，顶部是当前机构、服务状态和当前管理员。切换管理机构时必须清空当前页面筛选和详情，重新请求目标机构数据。成员、组织、内容、席位、审计都只显示当前机构。普通 Member 不出现管理入口，直达链接也应被拒绝；组织管理员只显示其被授权节点及下级范围内允许查看的页面和数据。

## 2. 页面职责和主要操作

| 页面 | 信息层级 | 主操作 | 次操作 / 详情 |
| --- | --- | --- | --- |
| 机构概览 | 状态提示 → 关键数字 → 待处理 → 最近活动 | 邀请成员 | 前往席位、内容、审计 |
| 成员管理 | 筛选栏 → 成员表（用户名、邮箱、手机号、一级至五级架构）→ 单人详情 | 邀请成员 | 设置一级架构并自动补全上级、编辑资料、变更角色、禁用/启用、移除 |
| 邀请记录 | 状态筛选 → 邀请表 | 新邀请 | 取消、重发、查看发送状态 |
| 组织架构 | 画布工具栏 → 节点及连线 → 节点详情侧栏 → 直属/汇总数字 | 新增或关联节点、保存架构 | 拖拽布局、调整连线、自动布局、停用、从全机构成员设置管理员 |
| 组织统计 | 授权节点 → 指标 → 趋势/成员列表 | 下钻下级节点 | 时间、成员和使用类型筛选 |
| 内容管理 | 类型页签 → 检索 → 列表 → 详情侧栏 | 查看详情 | 按成员/日期筛选、复制分享链接 |

| 使用与额度 | 席位指标 → 变化明细 → 积分用量 | 查看明细 | 时间及成员筛选 |
| 操作审计 | 时间、操作者、动作筛选 → 结果表 | 查询 | 查看请求 ID、对象摘要 |
| 机构信息 | 上游只读信息 → 同步状态 | 无 | 跳转支持或续约入口（有真实链接时） |

## 3. 关键交互路径

### 3.1 首位 Owner 首次进入

后台完成机构开通与指定 Owner → Owner 完成统一身份认证 → 点击 Alice 中机构管理入口或直接访问管理地址 → 如管理多机构先选择机构 → 进入概览。同步中、已禁用或无管理员权限时显示对应说明与返回入口。

### 3.2 邀请到使用

成员管理「邀请成员」→ 输入手机号和机构补充资料 → 表单校验 → 检查剩余席位 → 创建待接受邀请并显示预留 → 受邀人身份验证及接受 → 成员列表出现正常成员、预留转为占用。拒绝/过期/取消释放预留。原型中的「体验受邀流程」要求输入匹配手机号并确认机构内容告知，用于演示受邀侧；正式系统应由统一账号中心验证身份。

### 3.3 成员状态与数据

禁用后成员仍在默认列表，席位不变；启用恢复访问；移除后从默认列表隐藏，可通过「已移除」筛选和审计追查。内容仍归原机构成员工作区。原型列表和数量随操作改变，但刷新会恢复演示数据。

### 3.4 内容查看

先选类型，再按成员或关键词筛选；打开详情进入只读侧栏，显示内容类型、创建者、机构上下文及时间。管理员读取留审计记录。对于没有权限、内容被隐藏或资源不属于当前机构的请求，服务端须拒绝；原型仅模拟本机构内容。

### 3.5 功能权限

Owner 修改 Admin 管理动作与 Member 可用功能；保存前显示影响范围。上游未授权的功能不允许打开。权限变更会影响后续请求，并在审计中留记录。演示原型只模拟角色模板，不模拟真实服务端授权。

### 3.6 从下向上搭建组织架构

Owner/有权 Admin 进入「组织架构」→ 在空画布新建首个节点 → 点击节点连接点旁的“＋”新增上级或下级节点，或搜索并关联已有节点 → 拖动节点卡片整理画布位置 → 通过连接点拖线调整上下级关系 → 系统沿父链计算层级 → 校验单一父节点、不超过五级且不存在循环 → 保存架构。节点卡片展示组织名称、层级、管理员、直属用户数和包含全部下级的汇总用户数。

一级表示成员直接归属的最基层组织；二至五级为沿父节点向上的组织路径。机构可以只使用其中部分层级，未使用的层级不显示节点、在成员表中留空。

低保真页面结构：

```text
┌─────────────────────────────────────────────────────────────────────┐
│ 组织架构  [搜索节点]       [撤销][重做][自动布局][- 100% +][保存] │
├──────────────┬──────────────────────────────────┬───────────────────┤
│ 节点/未关联   │                                  │ 节点详情          │
│              │       可缩放、可平移画布          │ 名称 / 层级       │
│ + 新建节点    │   [五级] ─ [四级] ─ [三级]       │ 上级 / 下级       │
│ 未关联节点列表│                  └─ [二级] ─ [一级]│ 直属/汇总用户数   │
│              │          节点连接点与“＋”          │ 管理员成员选择器   │
└──────────────┴──────────────────────────────────┴───────────────────┘
```

- 拖动节点卡片只改变画布坐标，不修改组织关系。
- 从连接点拖出连线并连接节点，或使用“关联已有节点”，才新增或调整上下级关系。
- 节点保持单一父节点，页面拒绝循环连线、跨机构关联和超过五级的连接。
- 点击节点后在右侧面板编辑名称、查看关系和设置管理员；管理员选择器搜索全机构有效成员，不按所选节点过滤。
- 画布支持空白处右键/工具栏新建、框选移动、缩放、适应画布、小地图、自动布局、撤销/重做和离开未保存提醒。
- 解除关系、移动子树、停用节点等高影响操作，先展示受影响的成员路径、管理员范围和统计，再二次确认。

### 3.7 设置成员一级架构

成员可以一直保持未分配组织并正常使用机构工作区。有权管理员也可在成员详情选择一级架构 → 系统展示将自动带出的二至五级路径 → 确认保存 → 成员行、组织人数和后续使用统计更新。清空一级架构后，五级架构列均为空，该成员回到“未分配组织”筛选。移动成员或移动组织子树时需展示影响范围并记录变更前后路径。

成员列表固定展示「用户名、邮箱、手机号、一级架构、二级架构、三级架构、四级架构、五级架构」，角色、状态和最近使用作为附加管理列。窄屏优先保留用户名、一级架构和状态，其余层级放入横向滚动或详情面板。

### 3.8 组织管理员查看下级数据

组织管理员进入后默认落在其授权节点；可查看本节点及全部下级的直属/汇总用户数、用量和使用情况，并沿树向下钻取。父级、旁支和其他机构节点不出现在可选范围中，直接访问地址时服务端拒绝。拥有多个节点时提供授权节点切换，汇总数据对重复范围去重。

节点管理员由 Owner/有权 Admin 在节点详情侧栏中从全机构有效成员选择。候选人可以未设置组织，也可以属于其他组织分支；管理员的数据范围由被授权节点决定，与本人所属组织无关。

## 4. 通用状态与反馈

| 状态 | 页面表现 | 恢复动作 |
| --- | --- | --- |
| 首次空状态 | 说明为什么为空，提供符合权限的下一步 | 邀请成员或清除筛选 |
| 加载中 | 指标、表格使用占位；关键按钮防重复提交 | 等待，超时可重试 |
| 网络失败 | 保留当前筛选与输入，显示失败原因 | 重试 |
| 无权限 | 说明当前角色没有该机构操作权 | 返回概览 / 切换机构 |
| 机构禁用/到期 | 阻止机构工作区与写操作 | 查看机构状态或联系平台 |
| 无席位/超额 | 禁止新增邀请，展示总额/占用/预留 | 查看席位或联系平台扩容 |
| 邀请重复/身份不匹配 | 字段级错误，避免泄露账号是否注册 | 核对手机号 |
| 数据已变化 | 操作失败并刷新当前行和指标 | 重新确认 |
| 组织未建立 | 组织页提供创建首个基层节点；成员进入未分配视图 | 新建组织或设置一级架构 |
| 画布有未保存修改 | 顶部保存按钮显示修改状态；离开或切换机构时拦截提示 | 保存、放弃或留在当前页 |
| 非法节点连线 | 高亮问题连线并说明单父节点、循环、跨机构或层级超限原因 | 撤销连线或重新关联 |
| 超过五级/循环归属 | 阻止保存，定位导致问题的父子关系 | 调整上级节点 |
| 节点有成员或下级 | 禁止直接删除，展示受影响对象 | 先迁移成员/子节点或停用 |
| 组织范围无权限 | 不展示父级和旁支数据；直达请求拒绝 | 返回授权节点 |

## 5. 设备和界面原则

管理平台以桌面 Web 为主，建议内容区域最小支持 1024px。较窄窗口收起左侧导航，表格保留关键列，其他信息放入详情；移动端只保证基本可读和查看，不承诺完整管理操作。键盘可依次访问导航、筛选、表格、详情与弹窗；弹窗内焦点闭环，关闭后回到触发控件。状态不只靠颜色表达。

Alice 工作端的个人/机构工作区选择与切换沿用其产品框架；管理控制台使用独立后台布局。原型配色只是本项目演示稿视觉方案，不变更 Alice 用户工作端既有视觉。

## 6. 原型覆盖与限制

`原型/index.html` 当前覆盖概览、成员/邀请、内容、权限、席位积分、审计、机构信息，以及 Alice 上下文切换示意。可操作项包括机构切换、搜索/筛选、新邀请、受邀流程演示、成员编辑/禁用/启用/移除、权限保存、内容查看和审计记录联动。2026-10-13 新增的拖拽式组织画布、一级至五级自动路径、未分配成员、跨节点管理员选择和组织统计尚未进入静态原型，应在下一轮原型修订中补齐。Alice 工作区选择在本机浏览器保存，其他虚构数据刷新后恢复。原型不发起网络请求。登录、短信通知、上游同步、内容权限及席位原子事务只能在研发实现后验证。
