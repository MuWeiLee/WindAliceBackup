## 产品决策

- 保留现有单机构、亮色、单文件原型及组织画布、左侧菜单、顶栏路径、左下角用户菜单。
- Owner 默认管理所有组织节点，可查看机构总席位并设置组织节点的席位配额。默认管理权不占用某节点的直属成员名额。
- 显式设置的 Admin 必须是获授权节点或其下级节点的有效成员。Admin 可查看管理节点及下级的席位，向子节点分配配额，并向范围内指定成员分配席位；本人移出获授权节点的子树时，相应授权应失效。
- Admin 可查看授权节点及下级成员的用量和内容演示记录；无权查看其他分支或未分配节点的成员内容。
- 组织功能按具体项控制：技能、连接器、专家或功能模块逐项开通，新项默认关闭。Owner 下放的功能构成节点 Admin 的可调整范围；具体继承冲突规则仍待业务确认。
- 原型的席位总量、用量和内容均为本地演示数据，不代表合同、订单或线上计量结果。
- 原型以 24 个企业总席位作演示；每级节点的子节点配额与直属成员占用之和不得超过该节点配额。Owner 对节点下放某项功能后，原型暂按“本节点立即可用、下级继承、上级关闭后下级不可重新开启”演示；这是交互假设，不替代待确认的正式业务规则。

## 页面归属与操作

| 对象 | 页面或区域 | 操作 | 权限 |
| --- | --- | --- | --- |
| 企业总席位 | 概览、组织资源 | 查看 | Owner |
| 节点配额 | 组织资源、节点详情 | 查看、调整、向下级分配 | Owner；节点 Admin 仅在授权范围内 |
| 成员席位 | 组织资源、成员详情 | 指定、回收 | Owner；节点 Admin 仅在授权范围内 |
| 节点 Admin | 管理员、组织节点详情 | 设置、撤销 | Owner；候选人必须是该节点及下级的有效成员 |
| 成员用量和内容 | 使用情况 | 查询、查看详情 | Owner；节点 Admin 仅限授权节点及下级成员 |

## 边界与待确认

- 席位演示配额应满足“顶层节点配额之和不超过机构总席位；子节点配额与直属占用之和不超过父节点配额”，超配操作显示原因并阻止保存。
- 新建节点默认零席位，Owner 可在创建时设置。席位增减与合同起始时间的关系、转交时剩余积分及每日上限的精确结算不在本地演示中伪造。
- 上级关闭功能后子节点可否开启、Owner 下放后是否立即可用、文件资料的开通粒度、Admin 是否可查看内容全文，仍需业务确认；原型只展示脱敏的演示摘要。
- 原型按成员当前归属节点判断历史内容记录的可见范围；成员跨节点移动后，既有记录应按产生时节点还是当前节点授权，仍需确认。
- 席位转交与剩余积分继承已在会议中确认，但当前演示仅覆盖配额设置、向下分配及对成员分配/收回席位，不展示未经确认的积分结算数值。
