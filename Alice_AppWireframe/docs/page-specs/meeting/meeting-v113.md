# 会议模块 V1.13 页面决策记录

## 变更范围

- 用附件 `WindAliceMobile-Prototype_meeting_V1.13.html` 的会议模块替换原有会议模块。
- 保留 WindAliceApp 的 Demo / Component 外壳、375 × 812 手机框、底部输入框、TabBar 和其他业务模块。
- 不引入附件中的多设备演示外壳。

## 页面结构

| 页面 | pageId | 层级 / 导航 | 核心任务 |
| --- | --- | --- | --- |
| 我的参会 | `meeting-home` | 一级 / 1-D | 查看我的会议、预约、收藏和 AI 听会 |
| 全部会议 | `meeting-all` | 一级 / 1-D | 按状态、主题、类型和行业浏览会议 |
| 录音上传 | `meeting-upload` | 一级 / 1-D | 查看录音对象并发起上传 |
| 会议详情 | `meeting-detail` | 三级 / 3-A | 查看纪要、转写、音视频和边际变化 |

## 关键交互

- 主页面支持列表 / 日历切换与全部 / 今日 / 近三天 / 自定义时间筛选。
- Panel 顶部操作在“AI听会”和“录音上传”间随页面变化。
- 会议卡支持预约或收藏；详情返回进入前的来源页面。
- 详情提供复制、下载、星标和添加到文件夹。
- 底部输入入口打开会议小助手，可继续会议上下文问答。

## 复用与实现

- 复用现有页面壳、导航、Panel、底部输入框、TabBar、状态面板和图标资源。
- 全部样式内嵌在 `prototype/index.html`；V1.13 会议逻辑放在 `prototype/meeting-v113.js`，避免改动其他模块的既有实现。
- 不创建或引用独立 CSS 文件。

## 验证

- `app.js` 与 `meeting-v113.js` 均通过语法校验。
- 原型只引用本地资源。
- 无头 Edge 烟测通过：会议入口、列表、日历、Panel 主页面切换、详情转写、会议小助手、下载浮层。
