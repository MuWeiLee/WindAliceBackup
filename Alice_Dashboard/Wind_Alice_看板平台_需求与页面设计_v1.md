## 2. 需求结论

### 2.1 已确认需求

1. 新增独立一级模块「创意市场」，不再作为拓客服务 Panel 中的子项。
2. 创意市场包含「看板广场」和「我的看板」。
3. 看板广场包含官方看板与社区看板。
4. 我的看板包含「我收藏的」「我创建的」与「我分享的」。
5. 「我收藏的」中的看板是对原看板的引用对象。
6. 「我创建的」中的看板是 Work 结果对象，支持新建、改建，并可设置是否开启数字分身。
7. 拓客服务继续复用现有客户连接页面 `/link/clients`。
8. 客户连接支持进入某一个用户的具体对话并查看完整对话内容。
9. 基于看板发起的对话必须展示来源看板，采用类似淘宝订单卡片的结构化看板卡片，不仅以普通文本提示来源。
10. 看板卡片与具体对话绑定，用于说明用户查看了哪个看板后发起了该段对话。
11. Panel 固定采用「Drawer 抽屉头 → Group 分类 → Object 对象」三层语义；Drawer 和 Group 均不展示数量。
12. 拓客服务中「客户连接」是 Drawer，客户是 Group，客户与数字人的每段对话是 Object。
13. 创意市场中「看板广场」「我的看板」均为 Drawer；「我收藏的」「我创建的」「我分享的」是 Group，具体看板或分享记录是 Object。
14. 点击「看板广场」默认展示全部看板；该 Drawer 下方不展示任何 Group 或 Object，官方、社区和具体看板全部放在 Workspace 内容层。
15. 点击「我的看板」进入看板聚合页，以统一看板卡片展示收藏、创建和分享对象，而不是将三个分类平铺成功能入口。
16. 看板广场底部固定提供创建输入框，用户可直接描述并创建看板。
17. 点击看板卡片后，在当前 Workspace 上方打开右侧覆盖式看板抽屉；背景内容保留并弱化，不发生页面跳转。
18. 点击「我创建的」看板对象后进入双栏工作台：左侧创建对话，右侧完整看板。
19. 双栏工作台支持收起左侧对话以全屏展示看板、收起右侧看板以全屏展示对话，并可恢复双栏。
20. 看板抽屉顶部栏固定为「展开/收起｜看板名称｜做同款｜收藏｜分享｜关闭」。
21. 看板抽屉支持展开至整个 Workspace、恢复为右侧宽抽屉和关闭返回原广场位置。
22. 「做同款」在「我的看板 / 我创建的」新增 Work 结果，并立即进入对话工作台开始做同款。
23. 「收藏」在「我的看板 / 我收藏的」新增引用记录，不关闭抽屉、不改变当前页面。
24. 「分享」只在「我的看板 / 我分享的」新增分享记录，并保持当前看板抽屉；未执行分享的看板不进入该分类。
25. 看板广场内容层统一提供来源筛选、主题分类和排序，官方与社区列表使用一致的行间距、卡片间距和章节节奏。
26. 点击「我的看板 / 我创建的」中的对象直接进入创建对话与看板双栏，不打开看板展示抽屉。
27. 创意市场全部子页面顶部工具栏统一使用单行面包屑标题，不重复展示页面标题和状态 Pill。

### 2.2 产品关系

```text
创意市场：生产、收藏、分发看板
             │
             │ 用户查看看板并发起对话
             ▼
拓客服务：承接客户连接、对话内容和来源看板归因
```

## 3. 需求分析

### 3.1 需求陈述

- 业务目标：建立看板从生产、分发到客户对话承接的完整链路，使看板作者能够识别客户因哪个看板产生联系，并查看该客户的具体对话。
- 目标用户：看板作者、内容分享者、客户经理、查看看板并发起咨询的客户。
- 触发场景：客户在官方、社区或链接分享场景查看看板，点击数字分身或咨询入口并开始对话。

### 3.2 痛点

| ID | 痛点 | 用户角色 | 场景 | 设计节点 |
|---|---|---|---|---|
| P1 | 创意市场嵌套在拓客服务内，模块职责混杂 | 看板作者 | 查找、创建或管理看板 | 创意市场升级为一级模块 |
| P2 | 收藏看板与自建看板对象关系不清 | 看板作者 | 管理个人看板 | 我的看板分为我收藏的、我创建的 |
| P3 | 客户连接只能看到用户和对话，无法明确对话来源看板 | 客户经理 | 判断客户意图 | 对话顶部展示来源看板卡片 |
| P4 | 看板更新、下架后，历史对话可能失去上下文 | 客户经理 | 回看历史对话 | 保存对话发起时的看板快照信息 |

### 3.3 优先级

| ID | 影响 | 紧急度 | 置信度 | 优先级 |
|---|---:|---:|---:|---|
| P1 | 5 | 5 | 5 | P0 |
| P2 | 4 | 4 | 5 | P0 |
| P3 | 5 | 5 | 5 | P0 |
| P4 | 4 | 3 | 4 | P1 |

### 3.4 业务指标

| 痛点 | 指标 | 说明 |
|---|---|---|
| P1 | 创意市场入口访问率 | 衡量独立模块入口是否被使用 |
| P2 | 看板收藏、新建、改建完成率 | 衡量个人看板管理链路是否清晰 |
| P3 | 看板来源归因覆盖率 | 基于看板发起的对话中，成功关联来源看板的比例 |
| P3 | 看板到对话转化率 | 看板查看后发起对话的用户比例 |
| P4 | 历史对话上下文可恢复率 | 看板更新或下架后仍能识别原始上下文的比例 |

### 4.1 本期范围

- 创意市场升级为独立一级模块。
- 看板广场的官方、社区分类。

## 6. 创意市场页面设计

### 6.1 Page Shell

- 全局导航新增一级入口「创意市场」。
- 「拓客服务」中的现有「创意市场」Drawer 移除，避免两个入口指向同一对象集合。
- 创意市场使用标准 Global Nav + Panel + Workspace + Top Toolbar 页面框架。

### 6.2 Panel

#### 看板广场

- Drawer：看板广场。
- 点击 Drawer：Workspace 默认展示全部看板。
- Drawer 下不展示 Group 或 Object，也不提供具体看板快捷项。
- 官方、社区、主题分类、排序和具体看板全部由 Workspace 内容层承载。

#### 我的看板

- Drawer：我的看板。
- 点击 Drawer：进入看板聚合页，默认混合展示收藏、创建和分享对象。
- Group：我收藏的、我创建的、我分享的。
- Object：具体看板。
- 搜索范围：标题、作者；我创建的额外支持搜索来源看板名称。

#### 看板对象字段

| 字段 | 我收藏的 | 我创建的 |
|---|---|---|
| 标题 | 必须 | 必须 |
| 缩略图 | 必须 | 必须 |
| 作者 | 必须 | 当前用户 |
| 版本 | 社区发布版本 | 当前保存版本 |
| 来源 | 官方 / 社区 | 原创 / 改建自某看板 |
| 状态 | 正常 / 有新版本 / 已下架 | 私有 / 链接分享 / 社区发布 |
| 数字分身 | 展示是否可咨询 | 展示已开启 / 未开启 |

### 6.3 Workspace：看板广场

- P0：官方 / 社区切换、搜索、看板卡片、查看看板。
- P0：页面底部固定创建输入框，提交描述后直接进入看板创建工作台。
- P1：分类、排序、收藏、改建、数字分身标识。
- P2：收藏数、改建数、数据时间、作者信息。
- 展示模式：响应式卡片网格。

看板卡片至少包含：

- 缩略图。
- 看板标题。
- 作者。
- 版本号。
- 数据时间。
- 官方 / 社区来源。
- 收藏数、改建数。
- 数字分身标识。
- 快捷操作：做同款、收藏、分享。

点击看板卡片后，在 Workspace 内打开右侧覆盖式看板抽屉。抽屉默认覆盖主要内容区，背景页面保留并弱化；可展开至整个 Workspace，也可恢复宽抽屉或关闭。抽屉至少展示标题、数据时间、核心指标、趋势图、关键判断和明细数据。

### 6.4 Workspace：我的看板

- 页面核心是统一的看板卡片流，不使用三个功能入口平铺。
- 顶部展示全部、收藏、创建、分享的对象概览；下方提供分类筛选和统一排序。
- 卡片保持一致视觉结构，并通过类型标签表达所属分类。
- 收藏和分享卡片打开看板展示抽屉；创建卡片直接进入创建对话与看板双栏工作台。

#### 我收藏的

- 展示引用对象，不复制原看板。
- 原看板发布新版本时显示「有新版本」。
- 原看板下架时保留收藏记录并显示「已下架」。
- 操作：查看、改建、取消收藏。

#### 我创建的

- 展示 Work 结果对象。
- 支持原创、对话创建和做同款产生的看板。
- 展示分身开启状态。
- 操作：查看、继续编辑、分享、发布到社区、开启或关闭分身、删除。
- 点击具体对象进入双栏工作台：左侧为创建/修改对话，右侧为实时看板结果。
- 工作台支持三种布局：双栏、收起对话（全屏看板）、收起看板（全屏对话）；左右栏各自独立滚动，并在单栏状态提供恢复双栏入口。

#### 我分享的

- 仅展示用户已经执行分享后生成的分享记录。
- 创建中或尚未分享的看板不进入该分类。
- 分享记录保留来源看板、分享时间、链接状态和访问数据，并可返回查看来源看板。

### 6.5 Top Toolbar

创意市场所有子页面采用紧凑单行面包屑标题；不同时展示面包屑、页面大标题和状态 Pill。页面核心操作保留在右侧操作区。

| 页面 | 面包屑 | 主操作 | 次操作 |
|---|---|---|---|
| 看板广场 | 创意市场 / 看板广场 / 官方或社区 | 新建看板 | 搜索、分类、排序 |
| 我收藏的 | 创意市场 / 我的看板 / 我收藏的 | 无 | 搜索、筛选 |
| 我创建的 | 创意市场 / 我的看板 / 我创建的 | 新建看板 | 搜索、筛选 |
| 我分享的 | 创意市场 / 我的看板 / 我分享的 | 无 | 搜索、筛选、管理分享记录 |
| 看板展示抽屉 | 保留当前页面面包屑 | 做同款 | 收藏、分享、展开/收起、关闭 |

### 6.6 操作矩阵

| 对象类型 | 操作 | Owner | 位置 | 条件 | 结果 |
|---|---|---|---|---|---|
| 官方 / 社区看板 | 查看 | Content | 卡片 | 可访问 | 打开覆盖式看板抽屉 |
| 官方 / 社区看板 | 收藏 | Content | 卡片 Hover / 详情 | 未收藏 | 进入我收藏的 |
| 官方 / 社区看板 | 改建 | Content | 卡片 / 详情主操作 | 允许改建 | 新建 Work 结果 |
| 收藏看板 | 取消收藏 | Panel / Content | 更多菜单 | 已收藏 | 从我收藏的移除 |
| 自建看板 | 继续编辑 | Content / Toolbar | 主操作 | 当前用户拥有 | 返回原创建对话 |
| 自建看板 | 分身开关 | Content | 详情设置 | 当前用户拥有 | 更新分身状态 |
| 自建看板 | 删除 | Content | 更多菜单 | 当前用户拥有 | 确认后删除 |

## 7. 拓客服务·客户连接设计

### 7.1 复用原则

- 继续复用 `/link/clients`，不新建重复的客户管理页。
- 左侧 Panel 固定为「客户连接（Drawer）→ 客户（Group）→ 对话（Object）」结构。
- Drawer 和客户 Group 不显示数量；仅 Workspace 可展示汇总数量。
- 保留当前客户列表页和聊天内容主体。
- 移除拓客服务 Panel 中的「创意市场」入口。
- 本期核心增量是对话的来源看板归因与看板卡片。

### 7.2 客户连接列表页

每个客户条目包含：

- 头像和用户名。
- 最近一段对话标题或摘要。
- 最近活跃时间。
- 基于看板的对话数量。
- 最近来源看板名称；无特定看板时显示「来自创意市场」。

点击客户条目：

- Panel 选中该客户 Group 并展示其对话 Object。
- Workspace 进入该客户的对话记录列表，不默认打开最近一段对话。
- 用户点击具体对话 Object 或对话记录行后，进入完整对话内容页。

### 7.3 对话页

#### 页面层级

```text
拓客服务 / 客户连接 / 用户 / 对话标题
```

- 拓客服务顶部栏仅展示上述面包屑，并将其作为页面标题。
- 顶部栏不重复展示对话标题，不展示来源归因 Pill。
- 每个对话页面只加载当前客户、当前对话的消息，禁止穿插其他客户或其他对话的消息。

#### 内容顺序

1. 来源看板卡片。
2. 对话参与者与对话时间信息。
3. 完整对话消息流。
4. 对话加载更多或历史消息入口。

来源看板卡片固定放在消息流顶部，不作为普通聊天消息重复出现。用户滚动查看历史消息时，可根据产品实现选择吸顶精简态。

## 8. 淘宝订单式来源看板卡片

### 8.1 组件目标

像电商聊天中的订单卡片一样，用一个可识别、可点击、与对话绑定的结构化卡片说明本次咨询对应的看板。

### 8.2 卡片结构

```text
┌────────────────────────────────────────────────────┐
│ 来源看板                                  查看看板 → │
│ ┌──────────┐  美债收益率倒挂下的配置评估             │
│ │  缩略图   │  v1.2 · 作者 MUWEI                    │
│ │          │  数据时间 2026/09/24 10:30             │
│ └──────────┘  社区看板 · 用户于 11:02 查看后发起对话 │
└────────────────────────────────────────────────────┘
```

### 8.3 必须字段

| 字段 | 说明 |
|---|---|
| board_id | 来源看板唯一标识 |
| board_title | 看板标题 |
| board_thumbnail | 看板缩略图 |
| board_version | 用户发起对话时查看的版本 |
| board_author | 看板作者 |
| board_source | 官方 / 社区 / 链接分享 |
| data_timestamp | 看板数据时间 |
| viewed_at | 用户查看该看板的时间 |
| conversation_started_at | 用户发起当前对话的时间 |
| board_url | 打开看板的地址 |
| availability | 正常 / 已更新 / 已下架 / 无权限 |

### 8.4 快照规则

- 对话创建时保存看板卡片快照，至少保存标题、缩略图、作者、版本、来源和数据时间。
- 原看板更新后，历史对话仍展示用户发起对话时查看的版本。
- 原看板下架或删除后，卡片仍保留历史快照，但「查看看板」变为不可用并显示原因。
- 当前用户无权查看原看板时，保留标题、版本和来源，不展示受权限保护的看板内容。

### 8.5 卡片状态

| 状态 | 表现 |
|---|---|
| 正常 | 完整卡片，可打开来源看板 |
| 有新版本 | 显示「当前已更新至 vX」，仍保留对话版本 |
| 已下架 | 保留快照，操作按钮禁用，提示看板已下架 |
| 无权限 | 保留归因信息，点击时提示无查看权限 |
| 加载中 | 卡片骨架屏，不阻塞对话内容加载 |
| 加载失败 | 显示最小来源信息和重试入口 |
| 无特定看板 | 使用「来自创意市场」来源卡片，不展示缩略图与版本 |

### 8.6 交互规则

- 点击卡片或「查看看板」打开对应覆盖式看板抽屉；关闭后恢复原列表、筛选和滚动上下文。
- 从看板返回时恢复原对话、滚动位置和 Panel 选中状态。
- 卡片本身只承担上下文查看，不放置收藏、改建、分享等低频操作。
- 对话有多个看板来源时，以创建该段对话的首个来源看板作为主卡片；后续聊天中分享的其他看板按普通消息附件处理。

## 10. 页面状态与异常

- 客户无对话：显示空状态，引导等待客户发起咨询，不提供作者代客户创建对话。
- 用户有多段对话：Panel 按最近活跃时间排序，选中态只对应一段对话。
- 对话无看板来源：显示「来自创意市场」来源卡片。
- 对话消息加载失败：来源卡片仍可独立加载和展示。
- 看板卡片加载失败：不阻塞对话消息，提供重试。
- 看板已更新：历史对话不自动切换到新版本。
- 看板已下架或无权限：保留历史归因，不暴露无权限内容。
- 客户数量或对话数量较多：Panel 支持搜索用户名和对话标题。

## 13. 复用与设计约束

- 复用 Alice 全局导航、Panel Drawer、Group、Object Row、Top Toolbar、卡片、状态和空页面模式。
- 复用现有客户连接列表和对话消息流，不重构已确认的聊天布局。
- 新增组件为「来源看板卡片」及其状态变体，以及 Workspace 内的覆盖式看板展示抽屉。
- 来源看板卡片采用订单卡片的信息组织方式，但视觉 token、圆角、间距、字体和按钮仍使用 Alice 设计体系。
- 原型已按 `workspace内容模板库V2.html` 的深色 Global Nav、深色 Panel、激活 Drawer、Group 与 Object Row 逻辑实现。
