# 机构工作台｜本期数据字段

> 字段以 2026-10-14 最新讨论为目标口径。`目标`表示本期需要的数据或展示字段；`演示`表示当前原型已有；`待确认`不可视作已定接口合同。页面功能见[01_页面功能](01_页面功能.md)。

## 1. 对象与关联

| 对象 | 标识与归属 | 本期关系 |
| --- | --- | --- |
| 登录账号 | 账号 ID；个人身份 | 一个账号同时最多有一个有效机构成员关系；可拥有个人空间 |
| 机构成员关系 | 成员 ID、机构 ID、账号 ID | 每次加入产生新成员 ID；移除后再加入不复用旧关系 |
| 付费席位 | 不变的席位编号、所属机构、席位类型 | 一席同时绑定零或一名成员；一名成员同时最多持有一席付费席位 |
| 使用记录 | 记录 ID、产生时的成员 ID | 历史记录归属产生时的成员关系，不因再次加入合并 |

企业采购订单是席位的上游来源。席位应可追溯到订单，但订单与逐席编号、续费的详细映射仍待确认；机构工作台不维护订单。

## 2. 成员字段

| 字段 | 定义及规则 | 页面/状态 |
| --- | --- | --- |
| 成员 ID | 机构成员关系的唯一标识；重新加入时重新生成 | 目标：成员列表与记录列表统一显示；当前原型未完全展示 |
| 账号 ID | 登录身份内部标识，与成员 ID 不同 | 内部关联；当前原型记录列名“用户 ID”尚未统一 |
| 机构 ID | 成员所属机构 | 用于机构隔离；原型只有一机构演示 |
| 人名 | 机构维护的姓名，允许同名 | 新增、编辑、搜索、列表；演示 |
| 手机号 | 登录账号识别信息；机构内不可编辑 | 新增、搜索、列表；演示；全平台唯一范围待确认 |
| 邮箱 | 机构维护的联系信息 | 新增、编辑、搜索、列表；演示；是否必填待确认 |
| 加入时间 | 本次成员关系建立时间 | 列表；演示；再次加入重新计算 |
| 状态 | 启用、停用；移除表示关系结束 | 列表及操作；演示；停用仍占席位，移除释放席位 |
| 当前席位编号 | 成员当前绑定的零或一席付费席位 | 成员与席位关联；新增时选席位尚未实现 |

免费版是没有绑定付费席位的使用状态，不产生“免费席位编号”。成员总数、启用数、停用数只统计当前机构未移除的成员关系。

## 3. 付费席位字段

| 字段 | 定义及规则 | 页面/状态 |
| --- | --- | --- |
| 席位编号 | 单席固定标识；分配、换人、释放时不变 | 逐席列表；演示 |
| 机构 ID | 该席位所属机构 | 与成员机构必须一致；真实服务校验待接入 |
| 订阅订单关联 | 席位的采购来源 | 目标为可追溯；映射规则待确认；不在本期页面管理订单 |
| 席位类型 | 基础版、专业版、高级版、尊享版 | 卡片、筛选、列表；演示 |
| 剩余积分 | 留在席位上的余额，换人或释放不清零 | 逐席列表；原型仅静态演示，余额计算待确认 |
| 分配状态 | 已分配或待分配，由是否绑定成员得出 | 卡片、筛选、列表；演示 |
| 当前使用人 | 当前绑定的成员 ID，辅助展示人名与手机号 | 逐席列表；演示 |
| 到期时间 | 席位有效期结束时间 | 逐席列表；演示值；续费与到期处理待确认 |

四类付费席位按已购库存逐席展示。总席位数来自上游；本期工作台只分配已有席位，不调整采购数量与类型。

## 4. 使用记录字段

所有记录至少需要记录 ID、机构 ID、产生时的成员 ID 和事件时间，以便核对归属。历史人名应从当时的成员关系读取，不根据手机号合并新旧成员。

| 页面/记录 | 本期列表字段 | 补充要求 |
| --- | --- | --- |
| 对话内容 | 时间、成员 ID、人名、输入内容、输出内容、文件列表、操作 | 单成员查询；详情展示完整问答及文件 |
| 分享链接 | 时间、成员 ID、人名、分享类型、分享链接 | 分享类型：Link 看板、Chat 对话、单文件 |
| 文件下载 | 时间、成员 ID、人名、链接 | 分享和下载是两种独立事件 |
| 积分记录 | 时间、成员 ID、类型、描述、数量 | 数量是事件数值；与席位余额的逐笔对账规则待确认 |

当前原型四类记录的可见列仍采用“用户 ID”文案，字段规划采用“成员 ID”。正式实现需要统一标识含义与列名，避免把账号 ID 和成员 ID 混用。记录详情的脱敏、保留期和访问权限待确认。
