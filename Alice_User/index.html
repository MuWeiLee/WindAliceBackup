有效活跃
按当前自然月累计，本月每日完成一次有效活跃后计入连续天数；进入新月份后重新计算。
任务奖励
成长任务完成后自动发放奖励，用户无需手动领取；积分可用于对话及高级功能。
徽章奖励
仅由标有徽章的对应任务触发，用于记录能力成长，不作为兑换资产。
连续活跃转盘
本月连续活跃达到 7 / 14 / 28 天可兑换奖励；7 天、14 天各获得 1 张补签卡和 1 次转盘抽奖机会，28 天获得 3 张补签卡和 1 次转盘抽奖机会。
补登卡

任务领取

常见问题
为什么不用“登录连续天数”？
成长计划以“本月连续活跃”为展示口径，登录奖励与任务奖励分开展示，避免把任务完成和登录节点混在一起。
连续有效活跃如何计算？
按服务器时区的自然日统计，当前版本展示本月单月记录，不提供用户手动切换月份。
哪些任务可以获得徽章？
任务卡奖励区标注了“徽章”的任务可以获得徽章；完成并领取任务后，对应徽章会在上方任务徽章面板中点亮。
没有徽章标识的任务还有奖励吗？
有。没有徽章标识的任务仍按对应配置自动发放积分，只是不参与徽章解锁。
补登可以跨月续上吗？
不可以。连续活跃按自然月计算，新月份从 0 重新开始；补登卡只修复当前月内漏签。

密钥安全使用规范

为保障账号安全，请遵循以下规范使用 API 密钥：

  • 将密钥保存在环境变量或密钥管理服务中，避免硬编码在代码仓库。
  • 定期轮换密钥，减少泄露窗口。
  • 按最小权限原则为不同业务分配独立密钥。
  • 持续监控密钥调用日志，发现异常及时吊销。
  • 通过 HTTPS 加密传输，避免明文暴露在公网。
