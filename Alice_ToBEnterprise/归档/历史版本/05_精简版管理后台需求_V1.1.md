# 企业管理后台精简版需求 V1.1

> 历史版本：本轮统一评审口径已整理至 [10_企业管理后台_当前需求_V1.3.md](10_企业管理后台_当前需求_V1.3.md)。本文保留精简过程记录，不再作为当前主文档。

> 2026-10-13 · V1.1 当时的评审口径。以 `原型/企业管理后台_亮色.html` 为可操作页面；最新规则请参阅 V1.3。

## 1. 产品范围

以 Wind Alice V4 的亮色样式做独立管理后台。首版只保留两个机构管理角色：Owner 和 Admin。普通成员使用 Alice 工作区；组织节点管理员是节点数据查看授权，不另立第三种管理角色。

后台页面精简为：概览、成员管理、组织架构、使用情况、内容记录、管理员设置、操作记录。其中“管理员设置”仅 Owner 可进入；内容记录只读，覆盖对话请求、生成素材和分享记录。机构开通、席位额度和积分额度仍由上游系统提供。

## 2. 权限矩阵

| 操作 | Owner | Admin |
| --- | --- | --- |
| 查看机构概览、成员、组织、使用情况、操作记录 | ✓ | ✓ |
| 查看本机构内容记录与只读详情 | ✓ | ✓ |
| 添加普通成员 | ✓ | ✓ |
| 查询、编辑、禁用、移除、恢复普通成员 | ✓ | ✓ |
| 修改 Owner 或其他 Admin 的成员资料、状态 | ✓（不可移除唯一 Owner） | — |
| 新增、编辑、关联、调整、删除组织节点 | ✓ | — |
| 为组织节点指定或撤销管理员 | ✓ | — |
| 授予或撤销机构 Admin | ✓ | — |

Owner 是整个管理后台的最高权限角色。Admin 负责组织成员的增删改查；“删除”采用软移除，保留历史资料和操作记录，支持恢复。Admin 不能修改 Owner、其他 Admin、组织结构或角色授权。

## 3. 组织与成员

- 组织最多五级。成员只直接归属一个节点，可选择任意层级节点；列表中的“归属组织、上级组织……”按该节点的父链自动展示。新增下级节点不会迁移原节点的直属成员。
- 成员可以不设置组织架构，仍可正常使用机构工作区。未分配成员纳入机构总人数和席位，不纳入具体节点统计。
- Owner 从当前机构全体有效成员中选择节点管理员；候选人可以未分配组织，也可以归属其他组织。节点管理员只读被授权节点及其所有下级节点的成员信息、用户数和用量，不可查看其他分支。
- 每个节点分别展示直属成员和下级成员。Owner/Admin 可从节点内添加成员，新成员的归属固定为当前节点；节点管理员仅能查看。
- 成员列表展示用户名、邮箱、手机号、归属组织及最多四层上级组织，并显示身份、状态和操作。
- 组织页面采用亮色节点画布：拖动卡片调整展示位置，通过节点配置调整上级关系；保存时校验同机构、单父节点、无循环、最多五级。

## 4. 成员管理闭环

Admin 或 Owner 添加成员 → 填写用户名和手机号，邮箱与归属组织可留空；如从节点内添加，则固定归属当前节点 → 保存后进入机构成员列表 → 随时编辑资料、变更组织归属或禁用 → 移除时隐藏于正常列表并保留历史 → 有席位时可恢复。

当前单文件页面通过本机演示数据直接添加成员，用于验证后台信息架构和操作。真实系统仍需对接统一账号与身份确认，不能以浏览器里的演示保存结果作为账号开通或权限生效的依据。

## 5. 页面验收重点

1. Owner 可新增和调整组织节点、设置节点管理员、授予和撤销 Admin；Admin 视角无这些入口。
2. Admin 可新增、查询、编辑、移除与恢复普通成员，不能修改 Owner 或其他 Admin。
3. 未分配组织成员能保留在成员列表并计入机构总量；设置归属组织后自动展示上级路径。节点新增下级时，既有直属成员归属不变。
4. 组织关联不得出现循环或超过五级；节点有成员或下级时不能直接删除。
5. 成员和管理员变更有操作记录；移除成员保留历史数据。
6. 节点管理员可查看授权节点及下级的成员信息和用量，不能查看其他分支、未分配成员或执行成员变更。

## 6. 交付状态

`原型/企业管理后台_亮色.html` 是可直接打开的单文件交互演示。数据保存在本机浏览器中，切换 Owner/Admin/节点管理员用于评审页面差异。真实上线需服务端身份认证、机构隔离、权限校验、席位台账、计量和审计接口；前端隐藏不等于服务端授权。
