# Alice Tool - 工具模块与连接器抽屉需求文档

版本：V1.1  
日期：2026-09-22  
来源：基于 `Alice_Work_Connector` 既有原型与需求，按 Wind Alice 产品框架迁移到 `工具` 一级模块，并调整工具首页与 Panel 对象层结构。

## 1. 模块归属判断

本页面归属一级模块：`工具`。

连接器不作为导航栏一级模块。导航栏中激活的是 `工具`，连接器是工具模块下的顶层抽屉。

```text
工具
├── 我的工具
├── 专家
├── 技能
└── 连接器
```

## 2. 工具模块首页

点击一级导航 `工具` 后，工作区进入工具模块独立页面：`我的工具`。

`我的工具` 是工具模块首页，不是连接器概览页，也不是数据看板。它用于呈现用户高频使用的能力入口：

- 常用专家
- 常用技能
- 常用连接器

页面规则：

- 按专家、技能、连接器三个内容模块分区展示。
- 每个分区复用既有卡片/列表组件样式。
- 每个分区提供 `更多` 操作。
- 点击 `更多` 后切换到对应 Panel 抽屉头：专家、技能或连接器。
- 首页不展示概览类 KPI、状态统计、待处理数量等数据看板内容。
- 首页卡片点击后进入对应对象详情页。

## 3. Panel 结构

工具模块 Panel 下保留三个顶层抽屉：

```text
工具
├── 专家
├── 技能
└── 连接器
```

### 专家抽屉

专家抽屉的对象层平铺所有专家对象，目前不区分专家使用状态。

```text
专家
├── 个股研究专家
├── 行业研究专家
├── 宏观经济研究专家
├── 会议专家
└── 财富管理专家
```

点击专家对象后进入专家详情页。

### 技能抽屉

技能抽屉的对象层不是单个技能，而是技能筛选入口：

```text
技能
├── 最近使用
├── 已开启的
├── 官方技能
└── 社区技能
```

点击任一对象后，工作区进入对应技能筛选结果页面。筛选结果页再展示具体技能卡片，用户可从卡片进入技能详情页。

### 连接器抽屉

连接器抽屉的对象层调整为：

```text
连接器
└── 已连接
```

`已连接` 代表用户已经授权或已经完成接入的连接器集合。点击后进入已连接连接器列表页，再从列表进入单个连接器详情页。

## 4. 工具模块功能边界

本模块属于能力管理空间，不承载业务产物本身。

| 模块 | 边界 |
| --- | --- |
| 工具 / 专家 | 管理可被调用的专家 Agent 或专家角色能力 |
| 工具 / 技能 | 管理可复用的技能能力、官方技能和社区技能 |
| 工具 / 连接器 | 管理 Alice 可调用的外部服务和数据连接器 |
| Link | 管理客户连结、创意市场、客户材料和模板复用 |
| Work | 管理项目、任务、工作区和群聊工作对象 |
| 文件夹 | 管理本地、云端和上传文件对象 |

边界规则：

- `腾讯会议` 作为连接器时，属于 `工具 > 连接器`。
- 某次会议记录或参会记录，属于 `会议` 或 `Work`。
- 连接器产出的客户材料，属于 `Link` 或 `Work`。
- 连接器访问的文件对象，属于 `文件夹`。

## 5. 连接器对象定义

连接器对象是 Alice 可调用的外部能力接入。

对象项：`Connector Item`

对象项可以是：

| 对象类型 | 示例 | 说明 |
| --- | --- | --- |
| 单个连接器 | 腾讯文档、QQ 邮箱、腾讯会议、IMA、公众号 | 可授权、配置、启用、停用和调用 |
| 推荐组合 | 微信生态、知识库、邮箱、文档协作 | 表达一组连接器的协同场景，不产生独立授权状态 |

推荐组合不是独立连接器，不应拥有一键授权状态。组合详情中只展示成员连接器及各自连接状态。

## 6. 连接器列表页职责

页面名称：`已连接`  
所属抽屉：`连接器`  
类型标签：`连接器集合`

页面职责：

- 展示用户已经授权或完成接入的连接器。
- 支持从列表进入连接器详情页。
- 支持查看连接状态、授权状态和调用状态。
- 支持从连接器详情页进入设置、停用、启用或撤销授权。

不在已连接列表页承载完整配置表单。配置属于对象详情页或配置页。

## 7. 连接器详情页职责

点击单个连接器对象后，进入连接器详情页。

详情页职责：

- 展示连接器标识、名称、类别、开发者和状态。
- 展示连接器能力说明。
- 展示启用开关，区分已授权和已开启调用。
- 展示自然语言调用样例。
- 展示连接器信息：功能、开发者、类别、版本、启用状态、调用方式。
- 已连接时提供更多设置入口。
- 特殊连接器展示差异化能力，例如公众号订阅。

详情页状态规则：

| 状态 | 主按钮 | 启用开关 | 更多设置 | 样例点击 |
| --- | --- | --- | --- | --- |
| 未连接 | 连接 | 不展示 | 不展示 | 打开连接弹窗 |
| 已授权且已开启 | 立即体验 | 展示开启 | 展示 | 填入对话输入框 |
| 已授权但已关闭 | 立即体验置灰 | 展示关闭 | 展示 | 引导开启 |

## 8. 连接器操作

对象通用操作：

- 连接
- 立即体验
- 开启/关闭调用
- 配置连接器
- 状态刷新
- 撤销授权
- 查看能力样例
- 查看基础信息

连接配置页操作：

- 保存配置
- 状态刷新
- 允许 Wind Alice 调用
- 撤销授权

危险操作规则：

- 撤销授权必须收纳在更多设置或配置页中。
- 撤销授权必须二次确认。
- 撤销授权后清除授权状态和启用状态。
- 撤销授权不删除历史对话中的引用内容。

## 9. 连接器接入方式

沿用旧需求中的连接器接入方式：

| 接入方式 | 适用场景 | 当前连接器 |
| --- | --- | --- |
| OAuth 跳转授权 | 第三方平台提供用户授权页 | 腾讯文档、金山文档、百度网盘、Notion、钉钉、扫描全能王 |
| 访问凭证 | 用户填写 key、token 或授权码 | IMA、飞书、乐享知识库、网易邮箱、腾讯会议 |
| 管理员安装 | 需要企业管理员安装或组织授权 | 企业微信 |
| 内容源订阅 | 授权后还需要选择内容源 | 公众号 |
| 合作/暂不可自助接入 | 暂无稳定开放能力或需商务合作 | 知识星球、QQ 邮箱 |

## 10. 公众号连接器特殊能力

公众号连接器属于连接器对象，但具备订阅型差异化能力。

流程：

1. 用户连接 `公众号`。
2. 连接弹窗展示 `内容源订阅` 接入方式。
3. 用户开启连接器。
4. 用户进入公众号详情页。
5. 详情页展示公众号订阅模块。
6. 用户搜索公众号名称或微信号。
7. 用户订阅公众号。
8. Alice 后续只检索用户已订阅公众号的文章和更新。

规则：

- 未授权时不展示订阅模块。
- 已授权且已开启时可搜索、订阅并调用。
- 已授权但已关闭时保留订阅关系，但 Alice 不调用。
- 撤销授权后，订阅关系是否保留由后端策略决定，建议保留 30 天用于重新授权恢复。

## 11. 状态模型

连接器状态拆为三层：

| 状态层 | 含义 |
| --- | --- |
| 接入可用性 | 平台是否允许用户连接，例如可自助接入、需管理员、暂不可接入 |
| 授权状态 | 用户是否完成账号授权或凭证保存，例如未连接、已授权 |
| 调用状态 | Alice 是否允许调用，例如已开启、已关闭 |

调用前必须同时满足：

```text
已授权 + 已开启
```

## 13. 框架合规检查

- 导航栏承担一级模块，当前为 `工具`。
- `我的工具` 是工具模块点击后的独立工作区页面。
- Panel 承担当前模块下的对象目录。
- `专家 / 技能 / 连接器` 是工具模块下的顶层抽屉。
- 专家对象为具体专家。
- 技能对象为筛选入口，筛选结果页再承载具体技能卡片。
- 连接器对象层当前只展示 `已连接`。
- 搜索是行为，不是结构节点。
- 点击抽屉头打开对应抽屉工作区页面。
- 点击对象项打开对象详情页或筛选结果页。
- UI 效果不在本次结构调整中修改。

## 14. 不应设计的内容

- 不把连接器作为一级导航模块。
- 不把 `已连接 / 未连接 / 已关闭 / 待授权` 全部做成连接器抽屉。
- 不把推荐组合做成独立授权对象。
- 不在连接器列表页承载完整配置表单。
- 不把客户材料、会议记录、文件对象混入连接器对象。
- 不在 `我的工具` 首页堆叠概览类统计指标。
- 不借本次结构调整修改 UI 视觉效果。
