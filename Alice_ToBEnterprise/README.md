# 机构工作台｜本期需求

本期面向单个机构，当前按 Owner 视角整理。业务工作集中在成员、已购席位，以及对话、分享、下载和积分记录查询。企业创建、Owner 设置、采购席位与订单归上游企业管理系统。评审时先读[本期产品需求文档](机构工作台_本期PRD.md)。

| 本期主文档 | 内容 |
| --- | --- |
| [本期 PRD](机构工作台_本期PRD.md) | 可独立评审的完整产品需求，按页面功能、数据字段、计算逻辑与交互方法组织 |
| [01 页面功能](01_页面功能.md) | 六个页面、操作范围、原型已实现项与本期新增目标 |
| [02 数据字段](02_数据字段.md) | 账号、成员关系、付费席位、使用记录及字段归属 |
| [03 计算逻辑与交互方法](03_计算逻辑与交互方法.md) | 人数与席位计算、状态变化、分配约束、查询方式与待确认口径 |
| [本期原型](原型/机构工作台_本期.html) | 浏览器本地数据的单文件演示；[评审说明](原型/README.md) |

**阅读口径：**本期 PRD 是评审入口，三份专题文档便于按主题查阅。标为“本期目标、原型未实现”的功能包括新增成员时选席位、Excel 批量添加、成员 ID 展示及记录列名统一。真实账号、采购席位、内容和积分服务尚未接入；涉及规则待确认的地方不可直接视为已批准开发口径。

[未来计划](未来计划/README.md)集中放组织节点、节点 Admin、节点配额、功能开通等后续方向；[归档](归档/README.md)保存全部旧版需求、决策及原型，不作为当前版本依据。
