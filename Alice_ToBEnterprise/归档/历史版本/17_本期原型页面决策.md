## 页面结构

- shell：保留当前机构、侧边功能菜单、内容路径和左下角用户入口。
- 侧边导航：成员与席位／成员管理、席位管理；使用情况／对话内容、分享链接、文件下载；积分／积分记录。
- 各页面不在内容区重复显示页面标题。顶部导航栏承载面包屑与页面级主操作；内容区直接从概览卡片、搜索筛选和列表开始。没有概览卡片的记录页直接从筛选或内容模块开始。
- 列表搜索与筛选放在内容区工具栏；对象编辑、分配和确认使用现有弹窗样式。
- 对话内容以“搜索成员｜时间”作为筛选区：搜索仍是单个可搜索的成员选择框，按邮箱、手机号、人名筛选候选人，点击一位成员后只展示其记录；重新搜索或切换成员时清除上一人的结果，不提供全机构或多选入口。时间以平铺按钮呈现近1日、近7日、近1月、自定义，默认近7日；前三项按当前时刻滚动计算，自定义按起止自然日（含结束日）筛选，起止日期不完整或倒置时不展示记录。分享链接与文件下载是两个独立页面，不使用页内标签切换。

### 操作矩阵

| 对象 | 操作 | 位置 | 条件 | 结果 |
| --- | --- | --- | --- | --- |
| 成员 | 新增／再次加入 | 顶栏 | 当前机构无同手机号的未移除关系 | 新关系默认启用，生成新的关系 ID 与加入时间；旧关系及记录保留 |
| 成员 | 编辑 | 表格行 | 非移除成员 | 只修改人名、邮箱；手机号只读 |
| 成员 | 启用／停用 | 表格行 | 非 Owner、非移除成员 | 切换机构访问状态；停用继续占席位 |
| 成员 | 移除 | 表格行，二次确认 | 非 Owner 成员 | 关系隐藏并释放全部席位，旧关系及记录保留 |
| 机构采购席位 | 发起席位调整 | 席位管理顶栏 | 需要调整机构采购席位数量或类型 | 仅弹出办理提示：发起席位调整工单或联系销售；本期不在工作台内提交工单或修改采购席位 |
| 席位 | 分配 | 待分配席位行 | 席位未分配、成员已启用且未持有任何付费席位 | 该席位绑定成员，编号和剩余积分不变 |
| 席位 | 更换使用人 | 已分配席位行 | 目标成员已启用且未持有任何付费席位 | 席位直接绑定新成员，编号和剩余积分不变；不自动顶替目标成员已有席位 |
| 席位 | 释放 | 已分配席位行，二次确认 | 存在分配 | 该席位转为待分配，编号和剩余积分不变 |
| 席位概览 | 按类型筛选 | 席位类型卡片主体 | 点击某类型 | 清空席位搜索，下方列表展示该类型全部席位 |
| 席位概览 | 按待分配筛选 | 席位类型卡片“未分配席位”区域 | 点击某类型的未分配数 | 清空席位搜索，下方列表仅展示该类型待分配席位 |
| 对话 | 查看详情 | 表格行 | 已指定单个用户 | 右侧抽屉展示当前记录的完整问答、时间、用户及文件列表；支持关闭与 Esc |
| 对话 | 筛选时间 | 内容区筛选栏 | 已选择预设或填好有效自定义区间 | 仅改变当前选中成员的对话列表 |

## 信息层级

- P0：成员管理表格、成员总数及启用/停用数量；未分配席位成员卡片和四张付费席位概况卡片（席位类型、已分配/总席位、未分配）及逐席列表（席位编号、席位类型、剩余积分、分配状态、当前使用人、到期时间、操作）；单用户对话记录；分享链接列表（时间、用户 ID、人名、分享类型、分享链接）；文件下载列表（时间、用户 ID、人名、链接）；积分记录。
- P1：成员搜索、成员状态筛选、席位编号/使用人搜索、席位类型及分配状态筛选、对话时间筛选。
- P2：空状态和简短的列表计数。
- 顶栏：面包屑标识当前页面；成员管理显示新增成员，席位管理显示发起席位调整。后者只打开说明弹窗，不代表工单已提交。页面名不再在内容区重复出现；保留仅供辅助技术读取的隐藏标题。
- 复用：现有侧栏、顶部路径、统计卡片、表格、按钮、弹窗、确认与提示样式；席位概况增加第五张“未分配席位成员”卡片，计入当前机构全部未移除且未持付费席位的成员，卡内另示已启用且可分配的人数。席位类型卡片主体与“未分配席位”区域分别可点击并与列表筛选联动，小屏改为两列或一列。
- 成员搜索选择框：`#dialogPicker` 将输入与单选成员列表合为一个控件，聚焦即展开、列表限高滚动、输入按邮箱/手机号/人名即时筛选；鼠标点击或方向键加回车选中，Escape、Tab 或点击外部关闭。仅选中一位成员后加载对话；实现位于 `renderDialogues`、`openDialogPicker`、`closeDialogPicker`，沿用现有输入框、状态色及列表样式。
- 时间筛选：`#dialogPeriod` 为四个平铺的单选式按钮，使用 `aria-pressed` 表达当前项；选择自定义时沿用日期输入框，按自然日含结束日过滤；无效区间显示空状态，不发送或展示查询结果。内容列表列为时间、用户 ID、人名、输入内容、输出内容、文件列表、操作。
- 问答详情：`#dialogDetail` 为右侧原生 `dialog` 抽屉，只打开当前单条记录；展示完整输入、输出和文件列表，不新增执行或下载操作。关闭按钮、遮罩点击和 Esc 可返回列表，窄屏占满屏宽。
- 演示数据：增加跨成员、跨日期的对话记录；既有浏览器本地数据仅补入缺失的新演示记录，不重置成员、席位和已有记录。
- 分享链接与文件下载：复用现有表格和空状态，分别由 `renderShares`、`renderDownloads` 渲染；两页使用独立导航项和面包屑，不增加页内标签。用户 ID 取记录的账号 ID，人名按机构成员关系 ID 查找，以保留移除后重新加入的历史归属。

## 验收与例外

- [x] 功能菜单只出现本期六个页面，不显示对话汇总。
- [x] 成员、席位、内容、分享下载、积分字段按本期最新清单展示；每个付费席位一行，免费版不生成席位行。
- [x] 对话内容必须先通过同一个搜索选择框选中单个用户；搜索不直接展示对话明细，切换或重新搜索时不得混入前一用户记录；列表支持滚动、键盘选择和关闭。
- [x] 对话搜索按邮箱、手机号、人名筛选；时间提供近1日、近7日、近1月和自定义；列表展示时间、用户 ID、人名、输入内容、输出内容、文件列表、操作。
- [x] 时间选项平铺且单选状态清晰；自定义日期有效；查看详情打开右侧抽屉并只展示当前记录完整问答。
- [ ] 既有浏览器本地演示数据的自动补入逻辑已静态核对，仍需在用户当前浏览器刷新后确认新记录可见；不在验证脚本中改写用户保存的数据。
- [x] 分享链接与文件下载分别有独立菜单及面包屑；前者显示时间、用户 ID、人名、分享类型、分享链接，后者显示时间、用户 ID、人名、链接；无页内切换标签。
- [x] 移除成员释放席位，超配分配被拦截。
- [x] 停用保留席位；编辑成员时手机号只读；再次加入生成新的机构成员关系。
- [x] 释放或更换使用人不改变席位编号及原型演示余额；移除成员只解除绑定，不删除席位。
- [x] 新增分配遵循每名成员最多持有一个付费席位；分配与更换使用人的候选名单仅包括已启用且无付费席位成员，不隐式替换既有席位。既有演示重复绑定保留原状并提示人工选择释放，不能因缺少操作时间而自动决定保留哪一席。
- [x] 概览增加“未分配席位成员”；点击席位类型卡片筛选该类型全部席位，点击该卡“未分配席位”筛选该类型待分配席位，并同步下方筛选控件。
- [x] “席位配置”统一更名为“席位管理”；顶栏显示“发起席位调整”，点击后说明需通过工单或销售办理，本期不提供工单提交或直接修改采购席位；逐席分配、换人和释放保持不变。
- [x] 对话汇总的页面、导航入口及演示数据移出本期原型；单用户对话查询保持不变。
- [ ] 真实后端账号、采购席位、内容与积分数据对接（不属于单文件原型）。

旧原型的组织和节点功能没有迁入本期页面；历史业务讨论仍保留在原文档中，待后续重新排期。
