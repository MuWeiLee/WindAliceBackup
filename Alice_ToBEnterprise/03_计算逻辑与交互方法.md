# 机构工作台｜本期计算逻辑与交互方法

> 规则依据 2026-10-14 本期范围及字段规划。原型只验证页面交互；涉及跨机构、并发、权限、真实积分及内容数据的规则，需要由服务端落实。待确认问题集中列在文末。

## 1. 成员与席位计数

设当前机构中未移除的成员集合为 `M`，已采购的付费席位集合为 `S`。

| 指标 | 计算口径 |
| --- | --- |
| 成员总数 | `M` 的成员数，包含启用与停用 |
| 启用/停用数 | 分别统计 `M` 中对应状态的成员 |
| 未分配席位成员 | `M` 中当前没有绑定任何付费席位的成员；包括停用成员 |
| 其中可分配人数 | 未分配席位成员中状态为启用的人数 |
| 某类型总席位 | `S` 中该类型席位数 |
| 某类型已分配 | 该类型席位中当前绑定有效成员关系的席位数；停用成员仍算占用 |
| 某类型待分配 | 该类型总席位减已分配席位 |

免费版不计入付费席位库存和“某类型总席位”。席位编号、剩余积分留在席位对象上，释放或更换使用人均不改变这两项。原型中积分是静态演示值，不按对话或积分记录自动扣减。

## 2. 成员操作

1. **新增：**输入人名、手机号、邮箱；机构当前未移除关系中，相同手机号不可重复加入。成功后产生新的成员 ID、加入时间，状态为启用，默认不绑定付费席位。最新本期目标要求可在新增时选待分配席位，但具体选择规则尚待确认，当前原型需在席位页另行分配。全平台唯一机构关系须由真实服务检查。
2. **编辑：**仅改机构内人名和邮箱；手机号保持只读。邮箱是否必填待确认。
3. **停用/启用：**仅改变当前机构访问状态。停用继续计入成员总数并保留所占席位，但不能继续访问机构内容；已打开会话的失效细节待确认。
4. **移除：**二次确认后结束当前成员关系，释放其全部席位绑定；旧对话、分享、下载、积分记录仍归旧成员 ID。再次加入同一手机号时建立新关系，不继承旧席位或加入时间。

## 3. 席位分配与变更

- **候选成员：**必须属于当前机构、未移除、已启用且当前没有付费席位。一个成员最多同时持有一席付费席位；列表过滤之外，提交时服务端还须再次校验并保证并发操作不会造成重复绑定。
- **分配：**从待分配席位选择候选成员，建立绑定。席位编号和余额不变；已被他人抢先分配时提示状态变化。
- **更换使用人：**从已分配席位选择新的候选成员，直接改绑；不把旧使用人的对话或积分历史转给新人，也不自动释放新使用人原先可能持有的其他席位。
- **释放：**二次确认后解绑，席位变为待分配，编号、类型、余额保留。移除成员时执行同样的席位解绑。
- **历史冲突：**若旧演示数据出现一人占多席，显示冲突并让管理人员核对释放；不得按记录先后自动决定保留哪席。真实服务需保留审计信息并处理异常数据。
- **采购调整：**“发起席位调整”仅显示工单或销售办理指引；不改变库存。跨类型换档和积分结算待确认。

## 4. 查询与交互

| 场景 | 方法及边界 |
| --- | --- |
| 席位概览筛选 | 点击类型卡片显示该类型全部席位；点击其“未分配席位”显示该类型待分配席位；同步下方类型、状态筛选并清空席位搜索词 |
| 成员搜索 | 按人名、手机号、邮箱匹配；状态筛选仅改变当前列表 |
| 对话选人 | 一个可搜索的单选框，聚焦展示候选人，输入人名/手机号/邮箱缩小候选；未选中时不展示对话；重新搜索或换人清除旧结果 |
| 对话时间 | 默认近 7 日；近 1 日、近 7 日、近 1 月按查询时刻向前滚动；自定义按起止自然日且包含结束日；日期缺失或倒置时不展示记录 |
| 对话详情 | 从当前成员、当前时段的一条记录打开右侧抽屉，展示完整问答与文件；关闭、遮罩或 Esc 返回列表 |
| 分享/下载 | 独立页面查询，按产生时的成员 ID 关联历史人名；展示链接样例不表示真实产物可访问 |
| 积分记录 | 记录按产生时的成员 ID 归属；真实余额如何由流水、有效期和扣减规则计算仍待确认 |

## 5. 待确认口径与原型差距

| 问题 | 当前处理 |
| --- | --- |
| 手机号和机构归属的全平台唯一范围 | 原型只拦截本机构当前未移除关系的重复手机号；真实服务需跨机构校验 |
| 新增成员直接选席位、Excel 批量添加 | 已列为本期目标但原型未实现；具体席位选择、文件模板、顺序、异常行和部分成功规则待定 |
| 邮箱是否必填 | 新增与编辑展示，强制要求待定 |
| 席位与订单、续费、到期、跨类型换档 | 上游提供库存；生效、编号延续和结算规则待定 |
| 积分余额、每日上限、加油包 | 原型静态展示；正式计算公式、扣减及过期规则待定 |
| 停用后会话与分享链接 | 停用阻断机构访问已确定，具体失效时点待定 |
| 内容详情权限、脱敏和保留期 | 待产品、安全与业务确认；原型仅使用本地样例 |
| 节点 Admin 是否参加本期 | 当前只以 Owner 视角演示；角色范围未定，不能套用旧组织节点授权方案 |
