# 机构工作台｜本期原型

打开[机构工作台_本期.html](机构工作台_本期.html)查看六个本期页面。[预览图](机构工作台_本期_预览.png)可快速查看外观。`企业管理后台_亮色.html` 是旧地址的跳转页，也会进入本期原型。

建议依次检查：成员新增、编辑、停用与移除；付费席位的类型筛选、分配、换人和释放；单成员对话查询与右侧问答详情；独立的分享链接、文件下载及积分记录。

原型使用浏览器本地演示数据。新增成员时选席位、Excel 批量添加、成员列表显示成员 ID，以及记录列名统一为成员 ID 尚未实现；席位余额和到期时间仅是展示样例。真实服务端的权限、跨机构校验、数据采集与积分结算不由此原型验证。范围与规则见[本期三份主文档](../README.md)。
