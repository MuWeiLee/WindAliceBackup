## 产品与设计决策

- 这是独立的企业管理后台，不复用 Alice 主应用的三栏抽屉与输入框结构。
- 延续用户指定的 V4 亮色工作台方向，采用深蓝灰文字、冷灰底色和克制的蓝色操作色；不加入暗色版本。
- 用统一的线性 SVG 图标替换字符图标。Logo 使用页面内的简化 W 字形，不依赖外部品牌资源。
- 采用单侧栏，不保留只有一个入口的产品窄栏；数据卡片缩短高度，表格首列和操作列保持可见。
- 导航、页头、按钮、状态标签、数据卡片、表格、组织节点、详情侧栏、表单、弹窗采用统一圆角、边框、焦点与悬浮规范。
- 保留现有信息架构、组织数据和权限入口。成员可以归属任意组织节点，既有成员不会因新增子节点而被迁移；成员列名按“归属组织→上级组织”表示。

## 页面组件

| 范围 | 统一规则 |
| --- | --- |
| 导航 | 图标与中文标签并列，当前页使用浅蓝底色和左侧强调线 |
| 页头 | 面包屑、机构、身份与账号控件采用一套对齐与间距 |
| 数据卡片 | 图标、名称、数值三层结构，减少无含义装饰 |
| 表格与列表 | 清晰的表头、细边线、行悬浮与主次信息 |
| 组织画布 | 中性网格、蓝色连线、节点类型区分和明确的选中态 |
| 表单与弹窗 | 一致的输入高度、聚焦态、按钮层级与危险操作反馈 |

## 验收

- 所有页面的图标风格一致，不再混用 Unicode 符号。
- Logo、侧栏、页头和内容区形成统一的亮色视觉体系。
- 小屏幕下导航、卡片与组织画布仍可使用。
- 保持组织管理、成员、使用情况、内容、管理员及日志入口可用。
- 成员表横向浏览时，成员姓名和操作始终可见。

## 验证结果

- 桌面宽度下逐页检查导航与标题；组织画布显示 33 个预置节点。
- 新增子节点后，原节点成员的归属仍保留；编辑时可选所有组织节点。
- 管理员视角没有组织编辑入口，保留成员添加入口。
- 390px 窄屏没有页面级横向溢出，组织画布在自身容器内滚动。
- W 字形为原型用简化标识，正式上线需替换为获授权的品牌 Logo 资产。
