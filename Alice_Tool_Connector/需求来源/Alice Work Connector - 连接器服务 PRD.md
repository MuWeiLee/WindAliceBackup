## 1. 项目背景

- 业务背景：
  Alice 当前已经具备 Chat、Work 等核心工作入口，用户可以通过自然语言发起研究、写作、数据分析、会议纪要等任务。但真实办公场景中的上下文和数据往往分散在外部系统中，例如文档、网盘、邮箱、会议、企业 IM、知识库和项目管理平台。若 Alice 不能稳定连接这些服务，用户仍需要手动复制资料、下载文件、切换工具，AI 任务无法形成完整闭环。

- 问题现状：
  1. 外部服务能力缺少统一入口，用户不知道 Alice 能连接哪些工具。
  2. 添加外部服务的过程缺少产品化表达，用户无法在添加前理解连接器能解决什么问题。
  3. 已接入连接器缺少统一管理页，用户不容易确认连接状态、刷新状态、配置项和授权状态。
  4. 连接器能力与 Alice 对话、Work 项目、专家/技能体系之间的关系需要明确，否则容易被设计成复杂的运行监控后台，而不是用户可理解的能力市场。

- 改造目标：
  建立 Alice 连接器服务，作为外部服务连接中心，让用户可以发现连接器、搜索连接器、接入连接器、完成授权/配置、立即体验连接器能力，并在后续管理连接状态和授权关系。

- 预期收益（业务/体验/效率）：
  1. 业务：扩展 Alice 可处理的办公数据边界，为文档、邮箱、会议、知识库、网盘等场景提供连接基础。
  2. 体验：用户能在一个页面理解“有哪些连接器、能做什么、如何连接、连接后怎么用”。
  3. 效率：减少用户在外部工具和 Alice 之间手动搬运资料的成本。

## 2. 需求分析

- 用户角色与场景：
  1. 普通办公用户：希望连接邮箱、文档、网盘、会议工具，让 Alice 帮忙检索、总结、生成和整理内容。
  2. 研究/投研用户：希望连接知识库、文档、会议、网盘等来源，形成可追溯的分析上下文。
  3. 项目型用户：希望连接飞书、企业微信、腾讯文档、金山文档、知识库等团队协作系统，让 Alice Work 获取项目资料。
  4. 管理员/高级用户：关注授权范围、连接状态、刷新状态和撤销授权。

- 关键痛点：
  1. 用户不知道哪些外部服务已经支持连接。
  2. 用户在接入连接器前不知道连接器具体能用于哪些 Alice 任务。
  3. 用户接入连接器后需要看到连接状态、刷新状态和可继续操作。
  4. 用户需要能撤销授权，避免外部账号持续暴露给 Alice。
  5. 搜索连接器时需要快速定位，并且搜索词命中位置要清晰可见。

- 需求优先级（P0/P1/P2）：
  - P0：连接器入口、连接器列表、搜索、连接弹窗、连接流程、已连接状态、连接器详情页、立即体验、配置入口、撤销授权。
  - P1：连接器分类、搜索空状态、连接失败重试、授权失效提示、刷新状态详情、试用样例一键带入对话。
  - P2：团队级连接器分发、管理员审批、连接器运行日志、调用量统计、连接器开发者后台。

- 范围边界（In/Out）：
  - In：
    1. Alice 左侧顶部产品导航（Chat / Work / Link），Work 为当前入口。
    2. 侧栏「专家·技能·连接器」Hover 菜单，展开专家/技能/连接器三个选项。
    3. 连接器市场式卡片列表（含推荐组合区）。
    4. 推荐组合：作为推荐入口，展示组合名称、简介和包含连接器 logo，点击进入详情页逐个连接，本身无独立连接状态，不提供一键连接。
    5. 连接器搜索、高亮、清空。
    6. 连接器连接弹窗和连接流程。
    7. 连接器详情页中的连接状态、刷新状态、立即体验、配置、撤销授权。
    8. 连接器配置页：动态渲染连接器状态、允许调用开关、凭证字段（按连接器类型）、保存配置和状态刷新操作。
  - Out：
    1. 连接器调用量统计和健康检查仪表盘。
    2. 复杂审计日志。
    3. 团队级连接器分发和审批。
    4. 连接器开发者后台。
    5. 连接器计费。
    6. 外部服务 OAuth 细节实现，本 PRD 只定义产品流程和状态。

## 4. 功能框架

- 模块主页面：
  连接器列表页。用于发现、搜索、接入连接器，以及浏览推荐组合，是连接器服务的默认落地页。

- 次级页面：
  1. 连接器接入弹窗：用户点击 `+` 后出现，用于解释能力并发起连接。
  2. 连接器详情页：用户点击已接入连接器后进入，用于查看状态、立即体验、配置和撤销授权。
  3. 推荐组合详情页：用户点击推荐组合卡片后进入，展示包内相关连接器列表，支持逐个连接。
  4. 连接器配置页：用户从详情页点击配置后进入，动态渲染连接器状态、允许调用开关、凭证字段、保存配置和状态刷新操作。

- 页面关系图（文字版）：
  1. Alice 左侧顶部产品导航 Tab（Chat / Work / Link） -> 选中 Work -> 侧栏显示「专家·技能·连接器」。
  2. 侧栏 Hover「专家·技能·连接器」-> 展开 `专家 / 技能 / 连接器` -> 点击 `连接器` -> 连接器列表页。
  3. 连接器列表页 -> 推荐组合区 -> 点击推荐组合卡片 -> 推荐组合详情页 -> 查看相关连接器列表 -> 逐个连接。
  4. 连接器列表页 -> 搜索连接器 -> 过滤连接器卡片和推荐组合 -> 清空搜索 -> 恢复全部。
  5. 连接器列表页 -> 点击未接入连接器 `+` -> 连接器接入弹窗 -> 点击连接 -> 授权/配置 -> 连接成功。
  6. 连接器列表页 -> 点击已接入连接器卡片 -> 连接器详情页 -> 立即体验 / 配置 / 撤销授权。
  7. 连接器详情页 -> 立即体验 -> Alice 对话输入区，自动带入当前连接器上下文。
  8. 连接器详情页 -> 配置 -> 连接器配置页 -> 保存配置返回详情页 / 状态刷新重新读取状态。

## 5. 功能逻辑与链路

### 5.1 核心链路

1. 进入连接器页面：
   用户在 Alice 左侧顶部产品导航中选中 Work，侧栏显示「专家·技能·连接器」按钮。Hover 该按钮展开三个选项：专家、技能、连接器。用户点击连接器后进入连接器列表页。

2. 浏览推荐组合：
   页面顶部展示推荐推荐组合区域。每个推荐组合卡片包含名称、简介和包含连接器 logo 缩略图。点击推荐组合卡片进入推荐组合详情页。

3. 查看推荐组合详情：
   用户点击推荐组合卡片进入推荐组合详情页，页面展示推荐组合介绍及相关连接器列表。列表中每个连接器显示名称、简介和状态（已连接/连接按钮）。用户可逐个点击「连接」连接单个连接器。

4. 浏览连接器：
   系统以卡片网格展示全部连接器。卡片包含图标、名称、简介、添加按钮和连接状态。

5. 搜索连接器：
   用户在右上角输入搜索词，系统按连接器名称、描述、能力关键词以及推荐组合名称和描述实时过滤。命中内容高亮展示。用户可删除或清空搜索词，清空后恢复全部连接器和推荐组合。

6. 接入连接器：
   用户点击未接入连接器右上角 `+`，系统打开连接器接入弹窗。弹窗展示 Wind Alice 图标、目标连接器图标、标题、能力说明、连接按钮和试用样例。

7. 接入连接器：
   用户点击连接后，系统根据连接器类型执行连接流程：
   - 无需授权：直接连接成功。
   - 需要账号授权：跳转第三方授权或打开授权窗口。
   - 需要配置参数：进入配置流程。
   - 需要管理员权限：提示申请权限或联系管理员。

8. 管理连接器：
   已接入连接器卡片显示绿色状态点。用户点击卡片进入详情页，查看连接状态、刷新状态，并可立即体验、配置或撤销授权。

9. 配置连接器：
   用户从详情页点击配置后进入连接器配置页。配置页根据连接器类型动态渲染配置项：连接器状态（带状态圆点）、允许 Wind Alice 调用开关、凭证字段（如客户端 ID、访问密钥等，敏感字段以密码框展示）、操作区（保存配置、状态刷新）。保存配置后返回详情页；状态刷新重新读取连接器状态并显示提示。

### 5.2 关键规则

- 规则1：连接器页第一版定位为"连接器市场 + 连接/管理入口"，不承载调用量统计、运行监控和复杂审计。
- 规则2：`+` 只用于未接入连接器；已接入连接器不再展示 `+`，而是展示已连接状态或点击进入详情。
- 规则3：搜索词命中连接器名称、描述和推荐组合名称、描述时，需要高亮命中片段；搜索清空后恢复全部连接器和推荐组合。
- 规则4：连接弹窗必须在连接前说明连接器能力，并提供试用样例，降低用户理解成本。
- 规则5：所有需要授权的连接器，必须能在详情页撤销授权。
- 规则6：配置入口跳转页面，不在连接弹窗中承载复杂配置。
- 规则7：立即体验必须带入连接器上下文，避免用户连接成功后不知道如何使用。
- 规则8：推荐组合不是独立可连接实体，只是推荐入口。推荐组合本身没有"已连接/未连接"状态，只有包内的连接器有连接状态。推荐组合不提供一键连接功能。
- 规则9：推荐组合详情页中，每个连接器可独立点击连接，不依赖批量操作。
- 规则10：推荐组合详情页不提供撤销授权入口，撤销授权仅在单个连接器详情页操作。
- 规则11：进入连接器/推荐组合详情页时，隐藏顶部 Tab 切换和搜索筛选栏，仅保留返回按钮。
- 规则12：连接器配置页根据连接器类型动态渲染配置项：credential/app 类型显示凭证字段输入框（敏感字段以密码框展示），oauth 类型显示授权方式只读提示，blocked/workflow 类型显示对应状态说明。
- 规则13：连接器配置页的返回栏样式与详情页返回栏一致（sticky 定位、白色背景、底部边框），保持视觉统一。
- 规则14：状态刷新操作重新读取连接器连接状态和调用状态，刷新后显示"已刷新连接器状态"提示。

### 5.3 异常与兜底

- 异常场景：搜索无结果。
  - 提示与处理：展示空状态，提示“暂无连接器”。用户可通过搜索框清空按钮恢复全部连接器。

- 异常场景：连接失败。
  - 提示与处理：展示失败原因，允许用户重试或关闭弹窗。

- 异常场景：第三方授权取消。
  - 提示与处理：保持未连接状态，提示“授权已取消”，用户可重新点击连接。

- 异常场景：授权过期。
  - 提示与处理：连接器状态变为“授权失效”，卡片或详情页提供重新授权入口。

- 异常场景：刷新失败。
  - 提示与处理：详情页展示失败原因和最近成功刷新时间，提供手动刷新入口。

- 异常场景：连接器不可用。
  - 提示与处理：卡片置灰，说明不可用原因；不可点击添加。
