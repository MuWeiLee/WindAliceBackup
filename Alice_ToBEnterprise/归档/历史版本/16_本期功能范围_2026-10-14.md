# 机构工作台｜本期功能范围

> 状态：本期范围已按 2026-10-14 讨论收束；未明确的业务规则保留为待确认，不沿用旧原型自行推定。本文优先于本目录 V1.3 和节点权限原型决策；后者作为历史方案保留。

## 1. 需求陈述

- 目标：机构管理人员能维护机构成员、按已采购的席位类型分配席位，并按人查询对话与积分记录、查看分享下载行为。
- 目标用户：机构管理人员；本期原型以机构 Owner 视角演示。节点 Admin 是否参与本期、如参与其范围如何确定，待确认。
- 触发场景：新成员加入、成员资料与状态变化、席位分配或释放、管理人员查询成员使用情况。

## 3. 现状流程与本期目标流程

现有原型从组织节点、节点配额及权限出发，成员和用量依附于组织树；本期则需以成员和席位为入口。现有页面无法完整展示席位类型、对话输入输出、文件列表、分享类型与链接、积分流水。

```text
机构采购席位（上游） → 工作台查看各席位类型余量
                    → 新增/维护成员 → 为成员分配/释放席位
                    → 单用户查询对话
                    → 核查分享、下载与积分记录
```

## 5. 范围边界

- 本期页面不展示组织架构、节点席位下拨、组织权限开通、节点管理员设置、操作日志、企业订单和对话汇总。这些旧方案保留在历史文档，不代表永久取消。
- 企业总席位和席位类型来自企业管理系统或合同等上游；机构工作台仅展示和分配，不修改采购总数。
- 机构采购席位数量或类型的调整与现有席位的成员分配是两种操作。本期“发起席位调整”只提供办理指引：发起席位调整工单或联系销售；不在工作台内提交工单、修改订单或直接改变席位库存。
- 免费版不设席位上限，不生成逐席编号，也不计入付费席位库存；新增成员默认未绑定付费席位。付费席位有不可变的席位编号，未分配席位仍在席位列表中展示。席位转给新成员时，剩余积分随该席位保留；原成员的内容与使用记录不转移。每日上限、加油包与换档时的积分结算仍待确认，原型余额仅为演示数据。
- 当前机构每名成员同一时间最多持有一个付费席位，免费版为未绑定付费席位的状态。分配和更换使用人仅可选择已启用、且当前未绑定付费席位的成员；不采用“最新操作自动替换”。已有席位成员若要换档，应先通过明确的席位调整流程处理，跨类型积分如何结算仍待确定。概览“未分配席位成员”统计当前机构未移除且无付费席位的全部成员，并显示其中已启用可分配人数。原型会标出旧的重复演示绑定，由管理人员确认后手动释放其中多余席位；不自动决定保留哪一席，释放后席位编号和剩余积分保留。
- 正式服务端应以机构成员关系 ID 对有效付费席位绑定设置唯一约束；分配与更换使用人的提交须在同一事务中再次校验目标成员未占席，不能仅依赖候选名单过滤。若历史数据已冲突，应保留审计信息并由管理人员确认处理，不套用原型的演示数据修正规则。
- “启用/停用”是用户在当前机构下的访问状态，不是个人账号的状态。停用后仍属于当前机构、继续占用已分配席位，但不能访问机构相关内容；恢复启用后重新获得访问权。正式服务端需要在机构内容与接口上执行访问拦截，包括已有会话的处理。
- 成员移除时解除当前机构成员关系并释放该关系下全部席位；历史对话、分享下载、积分记录仍关联原成员关系保留核查。同一手机号再次加入时创建**新的机构成员关系**，加入时间重新计算，不沿用旧席位和旧关系状态。
- 手机号是账号识别信息，不在机构工作台的“编辑成员”中修改；内部账号 ID 与机构成员关系 ID 应区分。再次加入同一机构时账号 ID 可保持一致，但成员关系 ID 应重新生成。原关系和新关系的记录不得误合并。
- 对话内容必须单用户查询。搜索只用于定位候选用户，不直接触发全机构对话查询；未选中用户时不展示明细，切换或重新搜索用户时清除前一用户的查询结果。时间预设按当前时刻滚动计算；自定义按起止自然日（含结束日）筛选，日期不完整或倒置时不展示记录。历史记录按机构成员关系 ID 关联，移除后重新加入的关系不能混查。真实内容详情的隐私和权限控制另行确定。

## 6. 可度量结果与验收

| 痛点 | 设计流程节点 | 可度量指标 |
| --- | --- | --- |
| P1 | 成员管理 | 新增/编辑/状态切换/移除成功率；重复手机号拦截率 |
| P2 | 席位管理 | 席位编号唯一率；成员多席冲突数应为 0；各类型余量准确率；超配阻断率；释放后席位及余额保留一致率 |
| P3 | 对话内容 | 单用户查询完成率；跨用户记录误展示数应为 0 |
| P4 | 分享链接、文件下载、积分记录 | 事件入库完整率；用户与记录关联准确率 |

原型验收重点：当前机构有未移除关系的手机号重复加入被阻止；编辑时手机号不可修改；停用仍占席位；移除会释放席位；同一手机号再次加入生成新的关系与加入时间；席位逐席展示且编号不变，未分配席位可再分配，释放后演示余额保留；对话未选用户不展示内容，成员搜索、平铺时间筛选及七列字段符合本期要求，查看详情在右侧展示当前问答；分享类型和积分字段与本期要求一致。

## 7. 待确认与原型假设

1. 节点 Admin 是否参与本期；若参与，其组织管理范围是否沿用旧方案。原型暂用 Owner 视角，不对正式角色范围作结论。
2. 手机号“唯一”是 Wind Alice 全平台唯一，还是当前机构唯一？原型只在本地机构当前有效关系内拦截重复；跨机构校验需要服务端。同一手机号在该机构的旧关系已移除后允许重新加入，并建立新关系。
3. 席位类型目前有免费版、基础版、专业版、高级版、尊享版，其中免费版不是逐席库存。已按“一名成员最多一个付费席位”修正本期原型；跨席位类型调整时的积分结算与生效时间尚待确定，不在“更换使用人”中隐式处理。
4. 已确认停用保留席位；移除释放席位。仍待确定停用后已打开的机构页面与分享链接是否立即失效及会话清理细节。
5. 对话全文、文件链接、分享链接的保留期限、脱敏和访问权限待定；原型只用模拟资料。
