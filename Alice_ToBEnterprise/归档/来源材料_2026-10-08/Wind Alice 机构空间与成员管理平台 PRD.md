# Wind Alice 机构空间与成员管理平台 PRD

Oct 8, 2026 · @MU

## 1. 背景与范围

本期在 Wind Alice 中引入机构空间：同一账号可以进入个人空间和所属的机构空间，两者完全隔离；机构管理员在独立后台按手机号管理成员。账号模型参考 ChatGPT 的“账号 + 工作空间”方式。

**本期范围**

- 用户端：注册与登录时的空间选择、空间隔离、机构空间内的发布与分享限制、成员失效时的拦截
- 机构成员管理平台：成员添加、编辑、禁用、启用、删除，分享记录查看

**不在本期范围**

- 机构的开通、续费、停用：由其他平台负责，本产品只接收结果
- 积分规则：后续单独讨论
- 机构版与个人版的功能差异：本期两者功能一致
- 登录状态下切换空间：本期只支持退出登录后重新选择
- 一人多机构的专门说明：数据与选择页支持多机构，产品中不做额外提示

## 2. 名词定义

| 名词 | 定义 |
| --- | --- |
| 账号 | 一个手机号对应一个 Wind Alice 账号，归用户本人所有 |
| 个人空间 | 每个账号都有且仅有一个，归用户本人 |
| 机构空间 | 账号被某机构添加为成员后获得，每个所属机构各一个，数据归机构 |
| 机构 | 在开通平台完成开通的组织，本产品只读取其信息 |
| 管理员 | 有权登录机构成员管理平台、管理本机构成员的人 |
| 成员 | 被管理员按手机号添加进机构的账号 |
| 成员资料 | 管理员为成员填写的姓名、邮箱等信息，只作为机构内部记录，与用户账号本身的资料互不影响 |
| 禁用 | 成员暂时无法进入该机构空间；机构仍能在管理平台看到该成员；可恢复 |
| 删除 | 软删除：成员无法进入该机构空间，机构在管理平台也看不到该成员，数据在后台保留 |
| 分享记录 | 机构空间内每次创建分享链接时自动生成的记录，在管理平台可查 |

## 3. 账号与空间模型

一个账号下挂一个个人空间和零到多个机构空间；空间之间完全隔离，没有任何数据流转通道。

| 层级 | 归属 | 包含 |
| --- | --- | --- |
| 账号层 | 用户本人 | 手机号与登录方式、用户自己的姓名、邮箱、头像、系统设置 |
| 空间层 | 个人空间归个人，机构空间归机构 | 对话历史、Work 任务、看板（收藏与创建）、文件及文件路径、积分、定时任务、数字分身与拓客服务数据、分享链接 |

**隔离规则**

- 积分按空间独立计算和消耗，规则后续讨论
- 文件路径按空间独立，一个空间的文件在另一空间不可见、不可引用
- 空间之间不提供复制、移动、引用等任何流转能力
- 管理员填写的成员资料只在该机构内使用，不改写用户账号资料，也不在其他空间显示
- 机构版与个人版本期功能一致，差异仅在数据归属与发布、分享规则

## 4. 用户端需求

用户每次登录或注册完成时，系统检查该手机号的有效机构成员关系：没有则直接进入个人空间，有则进入空间选择页。

### 4.1 登录与注册

1. 已注册用户登录成功后，查询该账号下状态为“正常”的机构成员关系。
   1. 无：直接进入个人空间，不出现选择页。
   2. 有：进入空间选择页。
2. 未注册的手机号在注册时校验是否已被机构添加。
   1. 未被添加：完成注册后直接进入个人空间。
   2. 已被添加：完成注册后进入空间选择页。
3. 每次登录都重新选择，不记忆上次的空间。
4. 管理员添加成员后无需用户确认。用户处于登录状态时不做提示，需退出登录、重新登录后才在选择页看到新机构。

### 4.2 空间选择页

- 列出“个人空间”和所有状态为“正常”的机构空间，机构空间显示机构名称和 Logo
- 多机构直接并列，不做额外说明
- 已禁用、已删除的机构空间不出现
- 点选后进入对应空间

### 4.3 当前空间标识

- Web：Panel 层顶部显示当前空间名称（机构空间显示机构名称和 Logo）
- App：“我的”页顶部显示当前空间名称

### 4.4 切换空间

本期只支持退出登录后重新登录、重新选择，登录状态下不提供切换入口。

### 4.5 机构空间的发布与分享

- 禁止任何形式的发布。机构空间内隐藏所有发布入口，包括“发布到社区”（看板广场）
- 允许分享。机构空间内每次创建分享链接，同步生成一条分享记录写入管理平台
- 个人空间的发布与分享规则保持现状

### 4.6 成员被禁用或删除时

- 成员发起下一次请求时，服务端校验其在当前机构的成员状态
- 状态为“已禁用”或“已删除”：拦截请求，提示“你已无法访问该机构空间”，强制退出登录，回到登录页
- 重新登录后，选择页不再出现该机构

## 5. 机构成员管理平台

管理平台是独立的后台地址，只做 Web 端，只给机构管理员使用；它只管成员和分享记录，不涉及机构开通。

### 5.1 页面清单

| 页面 | 说明 |
| --- | --- |
| 登录页 | 管理员用手机号验证码登录 |
| 机构选择 | 管理员同时管理多个机构时出现，只管理一个时跳过 |
| 成员列表 | 默认首页，成员的查看、筛选与操作入口 |
| 添加成员 | 弹窗，按手机号添加并填写成员资料 |
| 编辑成员 | 弹窗，修改成员资料 |
| 分享记录 | 本机构空间内所有分享链接的记录 |

### 5.2 成员列表

| 字段 | 说明 |
| --- | --- |
| 姓名 | 成员资料，必填 |
| 手机号 | 添加时填写，不可修改 |
| 邮箱 | 成员资料，选填 |
| 其他资料 | 部门、职位等，具体字段待确认 |
| 状态 | 正常 / 已禁用 |
| 添加时间 | — |
| 最近进入时间 | 成员最近一次进入本机构空间的时间；从未进入显示“—” |
| 操作 | 编辑、禁用或启用、删除 |

- 支持按姓名、手机号搜索，按状态筛选
- 已删除的成员不出现在列表中

### 5.3 添加成员

- 只能按手机号单个添加，填写姓名（必填）、邮箱及其他资料
- 提交即生效，不需要被添加用户确认
- 已注册用户：重新登录后在选择页看到该机构
- 未注册用户：注册时即可看到该机构
- 手机号格式校验，同一机构内手机号不可重复

### 5.4 编辑成员

- 可修改姓名、邮箱及其他资料，手机号不可修改
- 修改只影响机构内部记录，不影响用户账号资料

### 5.5 禁用与启用

- 禁用需二次确认，确认后成员立即无法进入该机构空间
- 禁用后成员仍在列表中显示，状态为“已禁用”，资料可查看
- 启用后成员恢复访问，空间数据不变

### 5.6 删除

- 删除需二次确认，提示删除后在管理平台中无法查看和恢复
- 删除后成员从列表中消失，成员无法进入该机构空间
- 成员在该机构空间的数据在后台保留（软删除）

### 5.7 分享记录

机构空间内每次创建分享链接都会自动生成一条记录。

| 字段 | 说明 |
| --- | --- |
| 分享时间 | 链接创建时间 |
| 分享人 | 成员资料中的姓名 |
| 内容类型 | 对话、Work 结果、看板等 |
| 内容标题 | — |
| 分享链接 | 可点击打开 |

- 支持按时间范围、分享人筛选，按分享时间倒序排列

## 6. 成员状态规则

成员在机构中只有三种状态，只有“正常”可以进入机构空间。

| 状态 | 用户选择页 | 用户访问机构空间 | 管理平台成员列表 | 空间数据 | 能否恢复 |
| --- | --- | --- | --- | --- | --- |
| 正常 | 显示 | 可进入 | 显示 | 保留 | — |
| 已禁用 | 不显示 | 拦截并强制退出登录 | 显示，可查看资料 | 保留 | 管理员启用即恢复 |
| 已删除 | 不显示 | 拦截并强制退出登录 | 不显示 | 后台保留 | 管理平台内不可恢复 |

## 7. 校验与异常场景

| 场景 | 处理 |
| --- | --- |
| 添加的手机号格式错误 | 提交前提示，不可提交 |
| 添加的手机号已是本机构成员（正常或已禁用） | 提示“该手机号已在本机构中”，不可重复添加 |
| 添加的手机号尚未注册 | 正常添加；用户注册时校验到该机构，注册后进入选择页 |
| 用户已登录时被添加 | 不提示；退出登录、重新登录后可见 |
| 成员正在使用时被禁用或删除 | 下一次请求时拦截，提示后强制退出登录 |
| 同一账号在 Web 和 App 同时登录 | 各端各自选择空间，互不影响；成员失效时各端在下一次请求时分别拦截 |
| 用户在个人空间时，所属某机构的成员状态变化 | 不影响个人空间；下次登录时选择页按最新状态显示 |
| 机构空间内尝试发布 | 不提供入口；接口层同样拒绝来自机构空间的发布请求 |

## 8. 待确认事项

以下问题尚未讨论，每项附建议做法。

- [ ] 管理员从哪里来：初始管理员由开通平台指定？管理平台内能否把其他成员设为管理员？如何保证至少保留一位管理员？
- [ ] 已删除成员的手机号被重新添加：建议给一个全新的空空间，原数据继续在后台保留，不自动恢复
- [ ] 成员资料的其他字段：除姓名、邮箱外，是否需要部门、职位、工号
- [ ] 数字分身是否算“发布”：它对外部客户开放对话，建议本期在机构空间内一并关闭
- [ ] 成员被禁用或删除后，其创建的分享链接是否失效：建议失效，分享记录保留
- [ ] 已删除成员的分享记录在管理平台中如何显示：建议保留记录，分享人标注“已删除”
- [ ] 管理员能否在分享记录中撤销链接
- [ ] 用户更换账号绑定的手机号后，成员关系跟账号走还是跟手机号走：建议跟账号走
- [ ] 机构到期或停用（开通平台状态变化）时，机构空间如何处理
