# Wind Alice App 移动端原型参考说明

本目录用于给产品经理和 UI 设计师对照原型规划移动端页面。请优先按照现有模块分层，再选择对应顶部导航栏类型，最后把页面内容嵌入标准内容区。

## 1. 文件

| 文件 | 说明 |
| --- | --- |
| `../prototype/index.html` | 唯一原型入口，包含页面结构和全部样式，可直接打开 |
| `../prototype/app.js` | 通用页面数据与交互 |
| `../prototype/meeting-v113.js` | 会议模块数据与交互 |
| `../prototype/assets/` | 离线图标和示例图片 |
| `ui-reference-guide.md` | 本说明文档 |

## 2. 原型文件结构

`../prototype/index.html` 顶部有页面级 Tab：

`| Demo | Component |`

两个页面分别承载原型演示和组件库说明。

| 区域 | 作用 | 使用方式 |
| --- | --- | --- |
| Demo | 展示页面目录、375 × 812 手机画布、右侧状态切换 | 选中页面后，对照真实页面层级、输入框、底部 Tab、抽屉状态 |
| Component | 展示组件目录、手机内组件 Mock、右侧组件状态与可编辑文案 | 产品老师先在这里选择页面应使用的导航类型，并输入自己的页面文案验证效果 |

Component 不是业务页面，它和 Demo 共用同一套视觉样式、图标库和导航语义。后续新增页面或组件时，组件必须放在 375 × 812 手机画布中 Mock，不单独以网页卡片形式展示。右侧状态区允许输入页面名称、Tab 文案、子 Tab 文案、右侧功能和输入框占位，输入后会实时反映到手机 Mock 中。

Component 页面三栏结构：

`| 组件目录 | Demo | 状态 |`

Component 交互规则：

1. 左侧组件目录用于切换当前组件类型。
2. 组件按四类组合：导航栏、TabBar、输入框、内容层。每一类都必须有一个默认状态。
3. 导航栏必须选中一个类型，例如 `1-A`、`1-B-1`、`2-A-1`。
4. TabBar 可选 `底部主 TabBar` 或 `隐藏 TabBar`，默认显示主 TabBar。
5. 输入框可选 `底部输入框` 或 `隐藏输入框`，默认显示底部输入框。
6. 内容层可选 `空白内容层` 或 `内容占位层`，当前默认空白，后续可选配内容组件来假装页面效果。
7. 手机 Mock 内的顶部 Tab、子 Tab、底部 Tab 可以点击切换选中态。
8. 带 `>` 或 `⌄` 的标题区域可以展开下拉选单，并选择不同菜单项。
9. 手机 Mock 内的页面标题、Tab 文案、子 Tab 文案、输入框占位文字都支持直接点击编辑；编辑时不出现输入框外框。
10. 右侧状态区仍保留批量输入能力，适合一次性替换多个 Tab 或功能文案。

Demo 页面三栏结构：

`| 页面目录 | Demo | 状态 |`

Demo 固定使用 375 × 812 移动端手机画布。

## 3. 主模块与底部 Tab

底部 TabBar 支持用户自定义，但结构固定为：

`| Tab 1 | Tab 2 | Tab 3 | Tab 4 | 我的 |`

所有主模块都可以被用户选入前四个 Tab：

| 主模块 | 原命名 | 原型入口 | 默认位置 |
| --- | --- | --- | --- |
| 市场 | 首页 | `home-watch` | 底部 Tab 1 |
| 私人助理 | Chat | `chat-main` | 底部 Tab 2 |
| 协同工作 | Work | `work-dashboard` | 底部 Tab 3 |
| 拓客服务 | Link | `my-link` | 底部 Tab 4 |
| 会议 | 新增 | `meeting-home` | 我的瓷片区 |
| 文件资料 | 新增 | `files-home` | 我的瓷片区 |
| 自动任务 | 新增 | `automation-home` | 我的瓷片区 |
| 工具市场 | 新增 | `tools-home` | 我的瓷片区 |

未选入底部 Tab 的主模块，统一收纳到“我的”页面的瓷片区。当前原型默认底部为：市场、私人助理、协同工作、拓客服务、我的。

## 4. 页面层级规则

| 层级 | 含义 | 底部输入框 | 底部 TabBar |
| --- | --- | --- | --- |
| 一级 | 主模块入口或模块内主页面 | 显示 | 显示 |
| 二级 | 模块对象主页，例如项目详情、任务详情 | 显示 | 显示 |
| 三级 | 对象详情、内容详情、管理页 | 显示 | 显示 |
| 四级 | 设置、搜索、编辑、授权等流程页 | 默认不显示 | 按流程配置 |

原则：一级、二级、三级页面保持底部 Tab 稳定；四级页面必须明确配置。设置、搜索等仍需快速切换模块的页面可保留，菜单编辑、授权等聚焦型流程隐藏。底部激活项跟随所属模块；若模块未加入底部 Tab，则激活“我的”。

## 5. 顶部导航栏类型

### 1-A：一级频道型

结构：

`| 页面A | 页面B | 页面C | ... | 功能 | 功能 |`

用于同一主模块下的平级频道切换。

原型：

| 页面 | pageId | 导航 |
| --- | --- | --- |
| 市场-自选 | `home-watch` | `自选 / 热议 / 市场 / 持仓 + 搜索 + 通知` |
| 市场-热议 | `home-hot` | 同上 |
| 市场-市场 | `home-market` | 同上，内容层还有市场子 Tab |
| 市场-持仓 | `home-portfolio` | 同上 |
| 我的 | `mine` | `我的 / 服务记录 + 设置 + 通知` |
| 拓客服务 | `my-link` | `拓客服务 / 服务记录 + 设置 + 通知` |

市场页内容层子 Tab：

`全球 / A股 / 港股 / 美股 / 基金 / 银行理财 / 黄金 / 商品 / 货币 / 外汇 / 宏观`

默认选中 `A股`。内容层子 Tab 不改变页面层级。

### 1-B-1：一级对话主页型

结构：

`| = | Alice | > | 语音 | 新建对话 | 通知 |`

用于私人助理未开始对话状态。

规则：

| 元素 | 说明 |
| --- | --- |
| `=` | 对话 Panel，顶部固定有“新建对话” |
| `Alice` | 当前 Agent 或专家数字分身 |
| `>` | 切换 Agent / 金融专家数字分身 |
| 语音 | 快速进入语音输入 |
| 新建对话 | 创建新会话 |
| 通知 | 进入通知中心 |

原型页面：`chat-main`

### 1-B-2：一级对象列表型

结构：

`| = | 页面名称 | 功能 | 功能 |`

用于主模块的对象列表入口。

原型：

| 页面 | pageId | 导航 |
| --- | --- | --- |
| 协同工作-项目列表 | `work-dashboard` | `= / 项目列表 / 新建对话 / 通知` |
| 文件资料-文件夹 | `files-home` | `= / 文件夹 / 上传文件 / 新建文件夹 / 通知` |

协同工作的 `=` 为项目 Panel，顶部有“新建项目”。抽屉头为项目名称，对象为项目下的群聊对话。项目名称和对话对象都可点击。

### 1-C1：一级对话详情型

结构：

`| = | {对话标题} | 语音 | 新建对话 | 通知 |`

用于私人助理已开始对话状态。`=` 仍打开对话 Panel。

原型页面：`chat-detail`

### 1-D：一级带子 Tab 的模块主页

结构：

`| = | 页面名称 | 功能 | 功能 |`

`| 子Tab | 子Tab | 子Tab |`

用于主模块首页本身需要二级分类，但分类仍属于当前一级页面的情况。

原型：

| 页面 | pageId | 子 Tab |
| --- | --- | --- |
| 会议详情 | `meeting-detail` | 返回 / 会议纪要 / 录音转记 / 音/视频观看 / 边际变化 |
| 自动任务 | `automation-home` | 定时任务 / 提醒任务 |
| 工具市场 | `tools-home` | 技能 / 专家 / 连接器 |

### 2-A-1：二级对象详情型

结构：

`| = | {对象标题} | > | 功能 | 功能 |`

`| 子Tab | 子Tab | 子Tab |`

用于进入某个对象后的主页。

原型：

| 页面 | pageId | 导航 |
| --- | --- | --- |
| 项目详情 | `work-detail` | `= / {项目标题} / > / 新建项目 / 通知` + `动态 / 群聊 / 文件` |
| 任务详情 | `automation-task-detail` | `= / {任务名称} / > / 立即执行 / 通知` + `任务说明 / 执行记录` |

协同工作项目详情里的 `>` 用于快速切换项目。

### 3-A：三级详情型

结构：

`| < | 页面名称 | 功能 | 功能 |`

用于从上一级对象进入详情。

原型：

| 页面 | pageId | 导航 |
| --- | --- | --- |
| 项目群聊 | `work-group-chat` | `< / {对话标题} / 语音 / 新建对话 / 通知` |
| 个股行情 | `stock-quote` | `< / 股票名称 [代码] / 收藏 / 搜索` |
| 通知中心 | `notification-center` | `< / 通知中心 / 设置` |
| 文件夹 | `mine-files` | `< / 文件夹 / 新建文件夹` |
| 任务执行详情 | `automation-run-detail` | `< / {执行时间-任务名称} / 再次执行 / 通知` |

通知中心顶部不再出现通知铃铛，右侧仅保留设置。

### 3-B：三级带子 Tab 型

结构：

`| < | 页面名称 | 功能 | 功能 |`

`| 子Tab | 子Tab | 子Tab |`

用于“我的”内的管理类页面。当前仍保留兼容页面：

| 页面 | pageId | 子 Tab |
| --- | --- | --- |
| 自动任务 | `mine-automatic` | 定时任务 / 提醒任务 |
| 工具 | `mine-tools` | 技能 / 专家 / 连接器 |

新产品规划优先使用一级主模块 `automation-home` 和 `tools-home`。

### 4-A：四级设置型

结构：

`| < | 页面名称 | |`

原型页面：`settings`

设置页内容包含账号设置、账号安全、通用设置、通知设置、授权信息、隐私政策、服务协议、个人信息收集清单、第三方信息共享清单、关于、帮助与反馈、版本号、退出登录、注销账号。

## 6. 组件抽象字段

每个顶部导航栏组件可以抽象为以下字段：

| 字段 | 含义 | 示例 |
| --- | --- | --- |
| `level` | 页面层级 | `1`、`2`、`3`、`4` |
| `navType` | 导航栏类型 | `1-A`、`1-B-1`、`1-D`、`3-A` |
| `title` | 页面名称或对象名称 | `Alice`、`项目标题`、`通知中心` |
| `tabs` | 顶部频道 Tab 或子 Tab | `自选 / 热议 / 市场 / 持仓` |
| `leftAction` | 左侧入口 | `=`、`<` |
| `rightActions` | 右侧功能按钮 | `搜索`、`通知`、`新建对话` |
| `hasPanel` | 是否打开当前模块 Panel | `true` / `false` |
| `hasSwitch` | 标题是否支持快速切换对象 | `true` / `false` |
| `bottomInput` | 是否显示底部输入框 | 一级、二级、三级默认显示 |
| `tabbarOwner` | 底部 Tab 激活归属 | `市场`、`协同工作`、`我的` |

推荐写页面需求时使用这个格式：

```text
页面：项目详情
模块：协同工作
层级：二级
导航类型：2-A-1
顶部导航：= / {项目标题} / > / 新建项目 / 通知
子 Tab：动态 / 群聊 / 文件
底部输入框：显示
底部 Tab 激活：协同工作
Panel：项目 Panel，顶部 + 新建项目，抽屉头为项目名称，对象为项目群聊
```

## 8. 内容嵌入原则

1. 先判断页面属于哪个主模块，再决定底部 Tab 激活项。
2. 再判断页面是模块首页、对象主页还是对象详情，选择导航类型。
3. 页面内容只放在手机内容区，不重复顶部已有的搜索、通知、新建等功能。
4. 子 Tab 只切换当前页面内的数据域，不新增页面层级。
5. 一、二、三级页面底部都显示输入框，作为 Alice 当前上下文输入入口。
6. 如果某主模块未进入用户底部 Tab，必须能从“我的”瓷片区进入。
