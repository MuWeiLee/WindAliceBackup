# Wind Alice 成长计划埋点需求文档

> 版本：v1.0
> 日期：2026-09-23
> 适用端：WindAlice Web / PC / App
> 所属功能：成长计划（用户中心-个人中心）
> 所属页面ID：7938
> 所属页面名称：成长计划

## 1. 埋点范围

成长计划页面共设计 12 个功能点，覆盖页面载入、概览区领取 / 抽奖、成长任务、活跃日历、年度活跃记录、活动说明与常见问题折叠区。

1. 成长计划-页面载入
2. 成长计划-连续活跃奖励-领取奖励
3. 成长计划-转盘抽奖-立即抽奖
4. 成长计划-成长任务-去完成
5. 成长计划-成长任务-领取奖励
6. 成长计划-成长任务-展开全部
7. 成长计划-活跃记录-查看全年活跃记录
8. 成长计划-活跃记录-兑换奖励
9. 成长计划-活跃记录-查看日期活跃情况
10. 成长计划-活跃记录-确认补登
11. 成长计划-活动说明-查看活动说明
12. 成长计划-常见问题-查看常见问题

## 2. 参数约定

所有功能点通用参数如下：

```text
app_name: windAlice_web, windAlice_pc, windAlice_app
function_name: growthPlan
page_name: growthPlanPage
os: macOS, windows, iOS, android, harmonyOS
```

说明：

```text
app_name 默认三端；若后续仅部分端上线，按实际上报端收缩。
function_name=growthPlan 与 page_name=growthPlanPage 为本次新增取值。
target_event 为双向动作（展开/收起）时，Base 单选字段存主值 expand，方向说明已写入备注。
```

## 4. 分析口径建议

```text
页面载入（122）作为漏斗起点，可串联各操作功能点做转化分析：
连续活跃奖励领取（123）与活跃记录-兑换奖励（129）均记录里程碑节点组合，可按 7 / 14 / 28 天节点做奖励领取转化对比。
去完成（125）与领取任务奖励（126）按任务名称拆分，可评估各成长任务完成情况。
确认补登（131）可按补登日期统计补签卡使用趋势，与补签卡库存联动分析。
```
