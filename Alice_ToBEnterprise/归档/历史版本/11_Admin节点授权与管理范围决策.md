> 此文记录 V1.3 的节点授权口径。最新规则以[席位与节点权限原型决策](15_机构工作台_席位与节点权限原型决策.md)为准：节点 Admin 必须是获授权节点及其下级的有效成员，可查看授权范围内的成员用量和演示内容记录。

## 产品决策

- 后台只有 Owner 与 Admin 两类管理权限；不再单设全机构 Admin 和只读节点管理员。
- Owner 在组织节点详情或“管理员”页选取有效普通成员并指定节点，即授予该用户 Admin 权限。Admin 本人的成员归属可与授权节点不同，也可未分配。
- Admin 只能查看被授权节点及下级的组织、成员和用量；可在该范围新增、编辑、禁用、移除、恢复普通成员。新增或调整归属的目标节点也必须位于授权范围内。
- Admin 不能管理 Owner 或其他 Admin，不能修改组织结构、授予权限，也不能查看未分配组织成员和其他分支。
- 多个节点授权合并为查看与管理范围；撤销一项授权只移除对应节点及其下级范围。全部撤销后该用户不再具有后台 Admin 权限。

## 页面操作

| 对象 | 操作 | 位置 | 可操作人 | 结果 |
| --- | --- | --- | --- | --- |
| Admin 授权 | 设置、撤销 | 组织节点详情 / 管理员页 | Owner | 按节点授予或收回 Admin 管理范围 |
| 普通成员 | 新增、编辑、禁用、移除、恢复 | 成员页 / 节点成员区 | Owner；授权范围内 Admin | 成员保持单一直接归属 |
| 组织节点 | 查看成员和用量 | 组织架构 / 使用情况 | Owner；授权范围内 Admin | Admin 只能看到授权节点及下级 |
| 组织结构 | 新增、调整、删除 | 组织架构 | Owner | Admin 只读 |

## 页面与实现口径

沿用既有亮色单文件后台的导航、成员表格、组织画布、详情侧栏和弹窗。Owner 的“管理员”页改为节点授权清单，不再出现全机构管理员授权；组织侧栏中的节点管理员统一标为 Admin。顶部账号切换仅供评审身份视角，线上仍需服务端校验机构、节点、成员状态及授权关系。

原型使用原有本地演示数据；旧版 `role=admin` 标记会在读取时转为普通成员身份，实际 Admin 范围以节点授权为准。未带节点授权的旧机构管理员不会继续获得全机构权限。

## 验证

2026-10-13 使用独立浏览器环境检查：Owner 可为其他组织成员设置节点 Admin；Admin 只能看到授权子树，不能进入全机构内容与授权页面；可在范围内新增、编辑、禁用、移除和恢复普通成员，但不能编辑其他 Admin；新增和编辑时的归属选项仅限授权范围。原型脚本语法与上述页面交互均通过。
