# 机构工作台｜未来计划与待排期事项

> 本页仅整理曾提出的方向，不代表已经排入本期或完成业务审批。当前交付见[本期需求](../README.md)。详细原讨论保留在[归档](../归档/README.md)。

| 方向 | 已讨论的目标 | 进入实施前要确认 |
| --- | --- | --- |
| 组织架构 | 机构内最多五级节点、成员组织归属、节点管理员及组织统计 | 组织模型、节点移动及历史统计口径 |
| 节点 Admin | 按授权节点及下级管理成员、查看使用情况 | 是否参与近期版本、管理与内容查看范围、权限回收 |
| 节点席位配额 | Owner 向节点分配已购席位，节点 Admin 逐级下拨 | 总池、保留量、超配与缩容、合同时间基准 |
| 功能开通 | 按具体技能、连接器、专家和功能模块控制；新增项默认关闭 | 上下级开关继承、文件资料控制粒度、生效时点 |
| 积分扩展 | 每日上限、加油包有效期、席位换档结算 | 上限重置、扣减顺序、过期处理、对账公式 |
| 内容与审计扩展 | 执行记录、操作日志、组织范围内的内容查看 | 事件字段、隐私与脱敏、访问权限、保留期 |
| 企业管理系统 | 多企业创建、Owner 设置、企业总席位与订单管理 | 独立 PRD、运营角色和跨企业数据范围 |

以下问题虽在本期页面附近出现，仍需要单独决定，不能从旧原型推断：跨机构账号唯一性、新增/批量添加时的具体席位挑选、订单到逐席的关联、停用后已打开会话与分享链接的失效方式。
