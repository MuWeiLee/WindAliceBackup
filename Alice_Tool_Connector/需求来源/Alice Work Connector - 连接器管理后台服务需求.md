# Alice Work Connector 连接器管理后台服务需求

| 字段 | 内容 |
|---|---|
| 文档版本 | v1.0 |
| 日期 | 2026-08-25 |
| 状态 | Draft |
| 需求类型 | 后台服务需求 |

| 适用范围 | Alice Admin 后台、Alice 连接器前端展示数据服务 |

## 需求背景

Alice Work Connector 前端已规划连接器市场、连接器卡片、连接器详情、连接器包推荐等页面能力。当前连接器的真实接入方式差异较大，包含第三方平台、内部服务、文件型工具、知识库工具等，因此本期后台服务先管理连接器展示资料和运营配置，不处理连接器真实授权与调用流程。[PM判断]

如果每次新增连接器都依赖前端硬编码，连接器名称、简介、分类、标签、示例问句、上下架状态等信息无法由运营人员独立维护。连接器管理后台服务需要让 Admin 用户完成连接器登记、编辑、分类、标签、样板案例、连接器包关联和展示排序配置，并向前端提供稳定的数据来源。[PM判断]

## 需求目标

本期目标是建设一个连接器管理后台服务，使连接器资料可以在 Alice Admin 后台维护，并支持前端按连接器 ID、分类、标签、状态、支持端和展示配置读取连接器数据。

- Admin 可新增、编辑、下架、公开连接器。
- Admin 可自由创建连接器包，并在连接器包中添加或移除连接器。
- 前端可读取公开连接器并渲染连接器卡片、连接器详情和连接器包内连接器列表。
- 连接器支持中文和英文基础展示内容。
- 连接器可按分类和标签管理。
- 连接器包作为虚拟组合对象，用于把多个连接器打包给用户提供便捷的组合操作。
- 连接器展示排序从连接器主信息中拆出，按端、页面、分类独立配置。
- 本期不管理连接器授权方式、连接方式、调用方式和运行日志。

## 角色说明

| 角色 | 使用场景 | 主要权限 |
|---|---|---|
| Admin 管理员 | 维护连接器资料、连接器包、状态、分类、标签、连接器包关系 | 查看、新增、编辑、公开、下架、删除 |
| 运营人员 | 维护连接器文案、连接器包文案、图片、样板案例、展示排序 | 查看、编辑、展示配置 |
| 前端系统 | 读取连接器展示数据 | 只读公开数据 |

## 术语说明

| 术语 | 定义 |
|---|---|
| 连接器 | 前端展示的单个工具入口，例如飞书、Notion、百度网盘 |
| 连接器分类 | 连接器的主分类，一个连接器只能有一个主分类 |
| 连接器标签 | 连接器的辅助标记，一个连接器可以有多个标签 |
| 连接器包 | 多个连接器组成的虚拟运营组合，不代表一个真实可调用连接器，也不承载独立授权或调用能力 |
| 展示配置 | 控制连接器在不同端、不同页面、不同分类中的排序和可见状态 |

## 功能需求

### 1. 连接器列表

#### 页面布局

连接器列表页由筛选区、操作区、列表区组成。筛选区用于按连接器名称、连接器 ID、分类、标签、支持端、状态等条件查询连接器；操作区提供新增连接器、批量操作入口 `[假设-待确认]`；列表区展示连接器核心信息和单条操作入口。

#### 业务逻辑

当 Admin 进入连接器列表页时，系统默认展示未删除的全部连接器记录，并按更新时间倒序排列 `[假设-待确认]`。Admin 输入筛选条件后，系统刷新列表，只展示符合条件的连接器。列表中的连接器状态不影响后台可见性，不公开、公开、下架状态都应在后台列表中可查询。

#### 列表字段

| 字段 | 说明 |
|---|---|
| 连接器ID | 系统生成的唯一 ID |
| 连接器名称 | 默认展示中文名称 |
| 英文名称 | 连接器英文名称 |
| 所属公司 | 默认展示中文公司名 |
| 分类 | 连接器主分类 |
| 标签 | 连接器关联标签 |
| 支持端 | Web / Desktop / Mobile |
| 连接器版本 | 手动维护 |
| 连接器状态 | 不公开 / 公开 / 下架 |
| 是否关联连接器包 | 是 / 否 |
| 更新时间 | 最近一次保存时间 |
| 修改人员 | 最近一次保存的 Admin 用户 |
| 操作 | 查看、编辑、公开、下架、删除、展示配置 |

#### 筛选条件

| 条件 | 类型 | 说明 |
|---|---|---|
| 连接器名称 | 输入框 | 支持中文名、英文名模糊搜索 |
| 连接器ID | 输入框 | 精确或模糊搜索 `[假设-待确认]` |
| 分类 | 下拉单选 | 读取启用状态分类 |
| 标签 | 下拉多选 | 读取启用状态标签 |
| 支持端 | 多选 | Web / Desktop / Mobile |
| 连接器状态 | 多选 | 不公开 / 公开 / 下架 |
| 是否关联连接器包 | 单选 | 全部 / 是 / 否 |
| 更新时间 | 日期范围 | 按最近更新时间筛选 |

#### 边界与异常

| 场景 | 处理 |
|---|---|
| 无查询结果 | 展示空状态，并保留筛选条件 |
| 分类或标签已停用 | 历史连接器仍展示原有关联，但筛选项中默认不展示停用项 `[假设-待确认]` |
| 无权限访问 | 隐藏新增、编辑、状态修改等操作入口 |

### 2. 新增与编辑连接器

#### 页面布局

连接器新增/编辑页由基础信息、图片信息、分类标签、支持端、简介与能力、样板案例、连接器包关联、状态信息组成。页面底部提供保存、取消操作。编辑页额外展示创建时间、创建人员、更新时间、修改人员。

#### 业务逻辑

Admin 点击“新增连接器”后，系统进入新建表单，连接器状态默认为“不公开”。Admin 保存时，系统校验必填字段、图片规则、样板案例数量、示例问句数量和连接器包关系。保存成功后，系统生成连接器 ID，记录创建时间、创建人员、更新时间和修改人员。

Admin 编辑已有连接器时，连接器 ID 不允许修改。保存后，系统更新最新保存时间和修改人员。编辑公开连接器不会自动下架，前端读取到的公开数据以最新保存内容为准 `[假设-待确认]`。

#### 字段规则

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 连接器ID | 文本 | 是 | 系统生成，创建后不可修改 |
| 连接器名称（中文） | 文本 | 是 | 建议 2-30 字 `[假设-待确认]` |
| 连接器名称（英文） | 文本 | 否 | 建议 2-60 字 `[假设-待确认]` |
| 是否有连接器图片 | 布尔 | 是 | 是 / 否 |
| 连接器图片 | 图片 | 条件必填 | 选择“是”时必须上传 |
| 所属公司（中文） | 文本 | 否 | 连接器所属公司中文名 |
| 所属公司（英文） | 文本 | 否 | 连接器所属公司英文名 |
| 连接器分类ID | 单选 | 是 | 只能选择一个启用分类 |
| 标签 | 多选 | 否 | 可选择多个启用标签 |
| 支持端 | 多选 | 是 | Web / Desktop / Mobile 至少选一个 |
| 连接器简介（中文） | 文本 | 是 | 用于卡片或详情展示 |
| 连接器简介（英文） | 文本 | 否 | 英文展示文案 |
| 连接器能力（中文） | 文本 | 是 | 描述连接器可支持的能力 |
| 连接器能力（英文） | 文本 | 否 | 英文能力描述 |
| 连接器版本 | 文本 | 是 | 手动输入 |
| 连接器状态 | 枚举 | 是 | 不公开 / 公开 / 下架 |
| 是否关联连接器包 | 布尔 | 是 | 是 / 否 |
| 关联连接器包ID | 多选 | 条件必填 | 选择“是”时至少关联一个连接器包 |
| 创建日期 | 时间 | 自动 | 首次保存生成 |
| 创建人员 | 用户 | 自动 | 取 Admin 登录人 |
| 更新日期 | 时间 | 自动 | 每次保存更新 |
| 修改人员 | 用户 | 自动 | 取 Admin 登录人 |

#### 图片规则

| 项 | 规则 |
|---|---|
| 连接器图片 | 支持上传、替换、删除 |
| 图片格式 | PNG / JPG / JPEG / WEBP `[假设-待确认]` |
| 图片大小 | 建议不超过 2MB `[假设-待确认]` |
| 无图片状态 | 前端使用连接器中文名称首字；无中文名称时使用英文名称首字母 |

#### 状态流转

| 当前状态 | 允许操作 | 下一状态 |
|---|---|---|
| 不公开 | 公开、下架、编辑、删除 | 公开 / 下架 |
| 公开 | 下架、设为不公开、编辑 | 下架 / 不公开 |
| 下架 | 公开、设为不公开、编辑、删除 | 公开 / 不公开 |

### 3. 样板案例管理

#### 页面布局

样板案例位于连接器新增/编辑页内，分为样板图片区和示例问句区。图片区支持上传、预览、删除和排序；示例问句区支持新增、编辑、删除、排序和启用状态设置 `[假设-待确认]`。

#### 业务逻辑

Admin 可为每个连接器维护最多 10 张样板案例图片和最多 10 条示例问句。保存时系统校验数量上限。前端展示时按后台维护顺序输出；如果样板图片为空，则前端不展示图片模块；如果示例问句为空，则前端不展示示例问句模块。

#### 样板图片字段

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 图片 | 图片 | 是 | 单连接器最多 10 张 |
| 排序 | 数字 | 是 | 数字越小越靠前 |
| 是否启用 | 布尔 | 是 | 关闭后前端不展示 |

#### 示例问句字段

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 问句内容 | 文本 | 是 | 不能为空 |
| 语言 | 枚举 | 是 | 中文 / 英文 |
| 排序 | 数字 | 是 | 数字越小越靠前 |
| 是否启用 | 布尔 | 是 | 关闭后前端不展示 |

#### 边界与异常

| 场景 | 处理 |
|---|---|
| 上传超过 10 张图片 | 阻止上传并提示数量上限 |
| 示例问句超过 10 条 | 阻止新增并提示数量上限 |
| 删除已保存图片 | 二次确认 `[假设-待确认]` |
| 图片上传失败 | 保留当前表单内容，提示重新上传 |

### 4. 连接器分类管理

#### 页面布局

分类管理页包含分类列表、搜索、新增分类、编辑分类和状态切换。列表展示分类名称、分类 ID、状态、关联连接器数量、更新时间和操作入口。

#### 业务逻辑

Admin 新增分类后，分类可被连接器选择。一个连接器只能关联一个主分类。分类停用后，前端不再展示该分类筛选项，但历史连接器仍保留分类关系，后台编辑连接器时应提示该分类已停用 `[假设-待确认]`。

#### 字段规则

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 分类ID | 文本 | 是 | 系统生成 |
| 分类名称（中文） | 文本 | 是 | 不可为空 |
| 分类名称（英文） | 文本 | 否 | 英文展示 |
| 分类描述 | 文本 | 否 | 后台说明 |
| 状态 | 枚举 | 是 | 启用 / 停用 |
| 创建时间 | 时间 | 自动 | 系统生成 |
| 更新时间 | 时间 | 自动 | 保存时更新 |

#### 边界与异常

| 场景 | 处理 |
|---|---|
| 分类下存在连接器 | 不允许物理删除，允许停用 |
| 分类名称重复 | 阻止保存并提示重复 `[假设-待确认]` |
| 停用分类被连接器使用 | 保留关系，前端不展示该分类筛选项 |

### 5. 标签管理

#### 页面布局

标签管理页包含标签列表、搜索、新增标签、编辑标签和状态切换。列表展示标签名称、标签 ID、状态、使用连接器数量、更新时间和操作入口。

#### 业务逻辑

Admin 可创建启用状态的标签，连接器编辑页可多选标签。标签停用后，前端不展示该标签筛选项；已关联连接器的历史关系不删除。标签用于连接器检索、推荐和运营标记，不替代连接器分类。

#### 字段规则

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 标签ID | 文本 | 是 | 系统生成 |
| 标签名称（中文） | 文本 | 是 | 不可为空 |
| 标签名称（英文） | 文本 | 否 | 英文展示 |
| 标签状态 | 枚举 | 是 | 启用 / 停用 |
| 创建时间 | 时间 | 自动 | 系统生成 |
| 更新时间 | 时间 | 自动 | 保存时更新 |

#### 边界与异常

| 场景 | 处理 |
|---|---|
| 标签被连接器使用 | 不建议物理删除，允许停用 |
| 标签名称重复 | 阻止保存并提示重复 `[假设-待确认]` |
| 停用标签 | 前端不展示，后台保留历史关联 |

### 6. 连接器包管理

#### 页面布局

连接器包管理作为独立后台功能，由连接器包列表页和连接器包新增/编辑页组成。连接器包列表页展示连接器包 ID、连接器包名称、关联连接器数量、连接器包状态、更新时间和操作入口。连接器包新增/编辑页包含基础信息、关联连接器、样板案例和状态设置。关联连接器区域展示已选连接器列表，并提供添加、移除和排序入口 `[假设-待确认]`。

#### 业务逻辑

连接器包是虚拟组合对象，Admin 可以自由创建，用于把多个连接器组合成一个前端可展示的推荐包或便捷连接入口。连接器包不代表一个真实连接器，不拥有独立接入、授权、调用或运行能力；用户使用连接器包一键连接时，本质是对包内连接器逐个建立连接或加入用户连接器列表 `[假设-待确认]`。

Admin 新建连接器包时，系统生成连接器包 ID，默认状态为“不公开”。Admin 可填写中英文名称、中英文简介，添加一个或多个连接器，并维护连接器包自己的样板案例图片和示例问句。保存后，连接器包与连接器的关联关系独立存在，不修改连接器本身的基础资料。

连接器包公开后，前端可以展示连接器包卡片和详情页。前端展示连接器包时，应先判断连接器包状态；连接器包为公开时展示连接器包本身，但包内连接器列表应过滤不公开、下架或当前端不支持的连接器 `[假设-待确认]`。如果公开连接器包内没有任何可展示连接器，前端不展示该连接器包 `[假设-待确认]`。

前端“连接器包”区域即原型中的推荐组合区域。连接器包只提供组合展示和“一键连接”入口，不展示“组合技能”，也不生成独立技能能力项。当连接器包内所有连接器均为已连接状态时，前端隐藏连接器包的一键连接入口。

#### 连接器包字段规则

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 连接器包ID | 文本 | 是 | 系统生成，创建后不可修改 |
| 连接器包名称（中文） | 文本 | 是 | 前端中文展示名称 |
| 连接器包名称（英文） | 文本 | 否 | 前端英文展示名称 |
| 是否有连接器包图片 | 布尔 | 是 | 是 / 否 |
| 连接器包图片 | 图片 | 条件必填 | 选择“是”时必须上传 |
| 连接器包简介（中文） | 文本 | 是 | 用于连接器包卡片和详情页展示 |
| 连接器包简介（英文） | 文本 | 否 | 英文展示文案 |
| 关联连接器列表 | 多选列表 | 是 | 至少关联一个连接器 |
| 连接器包状态 | 枚举 | 是 | 不公开 / 公开 / 下架 |
| 创建日期 | 时间 | 自动 | 首次保存生成 |
| 创建人员 | 用户 | 自动 | 取 Admin 登录人 |
| 更新日期 | 时间 | 自动 | 每次保存更新 |
| 修改人员 | 用户 | 自动 | 取 Admin 登录人 |

#### 连接器包图片规则

| 项 | 规则 |
|---|---|
| 连接器包图片 | 支持上传、替换、删除 |
| 图片格式 | PNG / JPG / JPEG / WEBP `[假设-待确认]` |
| 图片大小 | 建议不超过 2MB `[假设-待确认]` |
| 无图片状态 | 前端使用连接器包中文名称首字；无中文名称时使用英文名称首字母 |

#### 关联连接器规则

| 规则 | 说明 |
|---|---|
| 添加连接器 | Admin 可从连接器库中搜索并添加连接器到连接器包 |
| 移除连接器 | Admin 可从连接器包中移除已关联连接器，移除关系不影响连接器主数据 |
| 连接器数量 | 一个连接器包至少包含 1 个连接器，数量上限 `[待确认]` |
| 连接器状态 | 不公开、公开、下架连接器均可在后台被选择 `[假设-待确认]`，前端展示时按连接器状态过滤 |
| 多包关联 | 一个连接器可出现在多个连接器包中 |
| 包内排序 | 支持维护连接器在连接器包内的展示顺序 `[假设-待确认]` |

#### 样板案例字段

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 样板案例图片 | 图片 | 否 | 单个连接器包最多上传 10 张 |
| 示例问句 | 文本 | 否 | 单个连接器包最多填写 10 句 |
| 语言 | 枚举 | 是 | 中文 / 英文，用于示例问句 |
| 排序 | 数字 | 是 | 数字越小越靠前 |
| 是否启用 | 布尔 | 是 | 关闭后前端不展示 |

#### 连接器包状态

| 当前状态 | 允许操作 | 下一状态 | 前端展示 |
|---|---|---|---|
| 不公开 | 编辑、公开、下架、删除 | 公开 / 下架 | 不展示 |
| 公开 | 编辑、下架、设为不公开 | 下架 / 不公开 | 展示 |
| 下架 | 编辑、公开、设为不公开、删除 | 公开 / 不公开 | 不展示 |

#### 边界与异常

| 场景 | 处理 |
|---|---|
| 关联连接器为空 | 阻止保存并提示至少添加一个连接器 |
| 删除公开连接器包 | 需先下架再删除 `[假设-待确认]` |
| 包内连接器全部不可展示 | 前端不展示该连接器包 `[假设-待确认]` |
| 添加重复连接器 | 阻止添加，并提示该连接器已在当前连接器包中 |
| 样板图片超过 10 张 | 阻止上传并提示数量上限 |
| 示例问句超过 10 句 | 阻止新增并提示数量上限 |

### 7. 展示配置

#### 页面布局

展示配置作为独立页面或连接器详情的子页面 `[待确认]`。页面按支持端、页面编码、分类筛选展示连接器排序列表。Admin 可调整展示排序、设置是否推荐、设置可见状态。

#### 业务逻辑

展示排序不写入连接器主信息。同一个连接器在 Web、Desktop、Mobile 可拥有不同排序；同一个连接器在连接器市场、Work Connector 页面、分类页也可拥有不同排序。前端读取连接器时，应先判断连接器状态和支持端，再结合展示配置决定是否展示和展示顺序。

#### 字段规则

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 配置ID | 文本 | 是 | 系统生成 |
| 连接器ID | 文本 | 是 | 关联连接器 |
| 支持端 | 枚举 | 是 | Web / Desktop / Mobile |
| 页面编码 | 文本 | 是 | 如 connector_market / work_connector |
| 分类ID | 文本 | 否 | 分类页排序时使用 |
| 展示排序 | 数字 | 是 | 数字越小越靠前 |
| 是否推荐 | 布尔 | 否 | 用于推荐区展示 |
| 可见状态 | 枚举 | 是 | 可见 / 不可见 |
| 更新时间 | 时间 | 自动 | 保存时更新 |
| 修改人员 | 用户 | 自动 | 取 Admin 登录人 |

#### 展示规则

| 条件 | 前端处理 |
|---|---|
| 连接器状态为公开 | 可进入展示判断 |
| 连接器状态为不公开或下架 | 不展示 |
| 当前端不在 supported_clients 中 | 不展示 |
| 展示配置为不可见 | 不展示 |
| 无展示配置 | 使用默认排序规则 `[假设-待确认]` |
| 排序值重复 | 按更新时间或连接器ID兜底排序 `[假设-待确认]` |

### 8. 前端读取规则

#### 业务逻辑

前端读取对象包括可展示连接器和可展示连接器包。可展示连接器需要同时满足：连接器状态为公开、当前端在支持端范围内、分类和标签可用、展示配置允许展示。可展示连接器包需要满足：连接器包状态为公开，且包内至少存在一个当前端可展示连接器 `[假设-待确认]`。前端不读取不公开和下架对象，除非进入后台预览模式 `[假设-待确认]`。

前端“我的”页面只展示用户已连接的连接器，不展示连接器包。连接器详情页不展示“技能”模块。连接器卡片未连接时展示“+”按钮，连接器详情和连接弹窗展示“连接”。连接器包未全部连接时展示“一键连接”，全部连接器已连接后隐藏该入口。连接弹窗使用标准化文案：标题为“连接{连接器名称或连接器包名称}”，说明为“Wind Alice 需要您的授权才可使用{连接器名称或连接器包名称}，点击连接并完成配置。”该弹窗只需要读取名称、图片或名称首字兜底、连接器包成员列表 `[按需]`。

#### 输出内容

| 数据 | 用途 |
|---|---|
| 连接器ID | 前端定位连接器 |
| 名称、简介、能力 | 卡片和详情页展示 |
| 连接器图片 | 卡片和详情页展示 |
| 公司信息 | 详情页展示 |
| 分类和标签 | 筛选和详情展示 |
| 支持端 | 判断当前端是否展示 |
| 样板图片 | 详情页展示 |
| 示例问句 | 详情页和快捷提问展示 |
| 连接器包ID、名称、简介 | 连接器包卡片和详情页展示 |
| 连接器包样板图片和示例问句 | 连接器包详情页展示 |
| 连接器包与连接器关系 | 连接器包详情页和组合操作展示 |
| 展示配置 | 排序、推荐、可见性控制 |
